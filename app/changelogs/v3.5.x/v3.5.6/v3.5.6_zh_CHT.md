## 概述

此版本改進了一些細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 在非 Chromium 核心的瀏覽器中使用時提醒相容性問題
* 改進 HTML 公式剪藏
* 在發布服務中移除收集箱
* 改進行動瀏覽器上的編輯工具列
* 改進 Esc 關閉公式編輯框後的遊標位置
* 匯出預覽模式支援渲染合併儲存格表格
* 合併儲存格表格在匯出 Markdown 時使用 HTML 標籤

### 修復缺陷

* 重建索引導致崩潰
* WPS 開啟 Excel 資源時內核崩潰
* 超連結網址遺失
* 回溯快照後文件內容未更新
* 資料庫搜尋框組合鍵異常

### 開發重構

* 修復內核 API `updateBlock` 清除文件資料的問題
* 插件支援將資料保存在子目錄
