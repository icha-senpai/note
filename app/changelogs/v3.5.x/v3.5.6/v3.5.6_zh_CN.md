## 概述

此版本改进了一些细节。

## 变更记录

以下是此版本中的详细变更。

### 改进功能

* 在非 Chromium 内核的浏览器中使用时提醒兼容性问题
* 改进 HTML 公式剪藏
* 在发布服务中移除收集箱
* 改进移动浏览器上的编辑工具栏
* 改进 Esc 关闭公式编辑框后的光标位置
* 导出预览模式支持渲染合并单元格表格
* 合并单元格表格在导出 Markdown 时使用 HTML 标签

### 修复缺陷

* 重建索引导致崩溃
* WPS 打开 Excel 资源时内核崩溃
* 超链接地址丢失
* 回滚快照后文档内容未更新
* 数据库搜索框组合键异常

### 开发重构

* 修复内核 API `updateBlock` 清除文档数据的问题
* 插件支持将数据保存在子目录
