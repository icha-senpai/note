## 概述

此版本改進了一些細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 解決點擊圖表塊和 PDF 連結導致的白屏問題
* 桌面端匯出 PDF 支援不分頁
* 改進 HTML 行級元素的剪藏
* 改進雙向關聯欄位的預設填入值
* `移動` 支援按文檔塊 ID 搜尋
* 改進集市插件的最低版本要求
* 隨機產生 Cookie 金鑰
* 改進點擊大綱和打開塊引用時的定位
* 改進超級塊的編輯與撤銷
* 支援鴻蒙端在離線時使用
* 改進模板函數 `ISOMonth`
* 支援配置 `最近的文件` 列出的最大數量

### 修復缺陷

* 無法在多個工作區之間切換發布服務
* 唯讀模式下無法跳轉搜尋結果
* 屬性值未進行轉義
* `updateBlock` API 遇到空指標錯誤
* `優化排版` 任務清單嵌套提示塊異常

### 開發重構

* 升級至 Electron v39.2.7

### 開發者

* 即使 `loadData` 函數執行失敗，插件也應該繼續運行
* 使插件命令和工具列的快捷鍵可選
* 改進插件資料儲存方法的錯誤處理與安全性
