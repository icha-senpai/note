## 概述

此版本改進了一些細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 將區塊圖示拖曳到停靠面板時編輯器不再捲動
* 圖表寬度變化後重新渲染
* 改進行動端的資源檔案編輯介面
* 改進閃卡互動
* 支援設定「開啟頁籤時不分割畫面」
* 修正對話方塊互動後 Windows 上的焦點問題
* 支援為表格設定標題
* 在微軟商店版本中不再自動設定 Pandoc 參數
* 改進導入 .sy.zip
* 在 Windows 和 macOS 的資源檔案選單中支援複製檔案
* 合併儲存格後改進換行處理 br
* 表格的右鍵選單支援一鍵插入多行多列
* 改進將區塊引用匯出為腳註
* 改進 HTML 清單剪藏
* 改進 HTML 區塊級元素中嵌套行級元素的剪藏
* 改善從右到左（RTL）方向的數學、表格、圖表和程式碼區塊的顯示

### 修復缺陷

* 在浮動視窗中刪除焦點區塊會導致控制台錯誤
* 鴻蒙系統升級後出現白屏或崩潰
* Windows 上無法匯出資源檔案
* 匯出 Markdown 時未匯出任何資源檔案
* 在某些情況下，main.js 在啟動時拋出錯誤
* 在 iPhone 上編輯器滾動緩慢
* 在某些 Android 裝置上鍵盤彈出後會自動收起

### 開發重構

* 升級至 Electron v39.6.1
