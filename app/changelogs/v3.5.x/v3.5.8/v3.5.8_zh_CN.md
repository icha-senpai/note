## 概述

此版本改进了一些细节。

## 变更记录

以下是此版本中的详细变更。

### 改进功能

* 将块图标拖动到停靠面板时编辑器不再滚动
* 图表宽度变化后重新渲染
* 改进移动端的资源文件编辑界面
* 改进闪卡交互
* 支持配置“打开页签时不分屏”
* 修复对话框交互后 Windows 上的焦点问题
* 支持为表格设置标题
* 在微软商店版本中不再自动设置 Pandoc 参数
* 改进导入 .sy.zip
* 在 Windows 和 macOS 的资源文件菜单中支持复制文件
* 合并单元格后改进换行处理 br
* 表格的右键菜单支持一键插入多行多列
* 改进将块引用导出为脚注
* 改进 HTML 列表剪藏
* 改进 HTML 块级元素中嵌套行级元素的剪藏
* 改善从右到左（RTL）方向的数学、表格、图表和代码块的显示

### 修复缺陷

* 在浮动窗口中删除焦点块会导致控制台错误
* 在鸿蒙系统升级后出现白屏或崩溃
* Windows 上无法导出资源文件
* 导出 Markdown 时未导出任何资源文件
* 在某些情况下，main.js 在启动时抛出错误
* 在 iPhone 上编辑器滚动缓慢
* 在某些 Android 设备上键盘弹出后会自动收起

### 开发重构

* 升级至 Electron v39.6.1
