## 概述

我們現在可以為發布服務設定文件級存取權限了：文件樹面板 - 更多 - 發布存取控制。

## 變更記錄

以下是此版本中的詳細變更。

### 引入特性

* 發布服務支援文件層級存取控制

### 改進功能

* 改進在程式碼區塊中的貼上體驗
* 初始化行動端插件側邊欄時清空容器內容
* 支援在瀏覽器中將檔案透過拖放上傳至資料庫資源欄位儲存格
* 支援將文件標題設為空
* 改進文件最後按 `↓` 鍵的互動方式
* 改進子級選單的顯示

### 修復缺陷

* 修正 `forwardProxy` 介面的 SSRF 漏洞

### 開發重構

* 升級至 Electron v40.8.0

### 開發者

* 使用 CSS 類別管理視窗狀態樣式
