## 概述

此版本改進了一些細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 改進文檔樹的拖放效能
* 改進從 ChatGPT 應用複製文本的體驗
* 最佳化匯出為 Word .docx 時資源的處理
* 撤銷應在回車後恢復遊標位置
* 改進資料庫資源欄位選單中圖片點擊的行為
* 插入大檔案（256MB）時顯示確認提示
* 改進 PDF 矩形註釋截圖的旋轉處理
* 改進匯出預覽模式
* Windows 端安裝後會自動刪除 `\%LOCALAPPDATA%\Scribli-updater\` 資料夾
* 最佳化錯誤視窗資訊佈局
* 資料同步後自動應用程式碼片段
* 改進搜尋結果開啟編輯器時的定位
* 提升 S3 資料同步與 RustFS 的相容性
* 支援清理臨時檔案
* 在提示塊和資料庫中修改表情不會更新常用表情清單
* 改進行動端資料同步後資源資料索引的更新
* 改進提示塊圖示的互動
* 改進桌面自動更新
* 剪下塊後動態載入文件
* 改進清單編輯中折疊標題的處理
* 支援將程式碼塊匯出為檔案
* 改進 PlantUML 的 PDF 匯出
* 改進 HTML 塊解析
* 改進表格複製
* 改善可折疊列表塊中 Mermaid 塊的渲染
* 發佈服務關閉時自動關閉瀏覽器頁面
* 改進在提示、引用和清單項目中折疊標題指示器的顯示

### 修復缺陷

* 搜尋時文件標題顯示不正確
* 分組視圖下資料庫單元格拖放填充行為異常
* 唯讀模式下點選文件會導致錯誤
* 多工作區存取鑑權錯誤

### 開發者

* 新增內部核心 API `/api/block/getBlockKramdowns`
