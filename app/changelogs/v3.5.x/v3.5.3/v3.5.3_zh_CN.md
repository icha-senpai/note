## 概述

此版本改进了一些细节。

## 变更记录

以下是此版本中的详细变更。

### 改进功能

* 改进文档树的拖放性能
* 改进从 ChatGPT 应用复制文本的体验
* 优化导出为 Word .docx 时对资源的处理
* 撤销应在按回车后恢复光标位置
* 改进数据库资源字段菜单中图片点击的行为
* 插入大文件（256MB）时显示确认提示
* 改进 PDF 矩形注释截图的旋转处理
* 改进导出预览模式
* Windows 端安装后会自动删除 `\%LOCALAPPDATA%\Scribli-updater\` 文件夹
* 优化错误窗口信息布局
* 数据同步后自动应用代码片段
* 改进搜索结果打开编辑器时的定位
* 提升 S3 数据同步与 RustFS 的兼容性
* 支持清理临时文件
* 在提示块和数据库中修改表情不会更新常用表情列表
* 改进移动端数据同步后资源数据索引的更新
* 改进提示块图标的交互
* 改进桌面自动更新
* 剪切块后动态加载文档
* 改进列表编辑中折叠标题的处理
* 支持将代码块导出为文件
* 改进 PlantUML 的 PDF 导出
* 改进 HTML 块解析
* 改进表格复制
* 改善可折叠列表块中 Mermaid 块的渲染
* 发布服务关闭时自动关闭浏览器页面
* 改进在提示、引用和列表项中折叠标题指示器的显示

### 修复缺陷

* 搜索时文档标题显示不正确
* 分组视图下数据库单元格拖放填充行为异常
* 只读模式下点击文档会导致错误
* 多工作区访问鉴权错误

### 开发者

* 添加内部内核 API `/api/block/getBlockKramdowns`
