## 概述

此版本改進了大量細節，優化了資料同步效能。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 支援在填寫資料庫關係欄位時建立新條目
* 右鍵選單支援對多個選取文件或塊進行更多複製選項
* 改進水平佈局的間距和寬度
* 改進圖片寬度設定
* 支援將資源檔案拖曳到資料庫和屬性面板中的資源欄位
* 改進子清單包含清單和普通塊時的換行行為
* 調整編輯器寬度後保持塊位置
* 文件樹「複製」支援使用快速鍵
* 對於沒有建立填空卡片的閃卡塊取消「顯示答案」
* 改進將標題或清單項目拖曳到文件樹
* 改進搜尋高亮
* 交換文件樹上的 拖曳 和 Alt+拖曳
* 資料庫支援計算欄位的「唯一值百分比」
* 改進文件歷史介面
* 改進行級元素查找替換
* 圖片與 IFrame 使用延遲載入
* 改進資料同步效能
* 新增選取塊和總塊的統計
* 改進撤銷後的遊標位置
* 改進導入 Markdown
* 改進資料庫屬性面板樣式
* 改進 HTML 剪藏
* 改進全選後貼上和複製程式碼塊
* 改進匯出 Markdown
* 匯出檔案名稱中的特殊字元替換為`_`
* 改良拖曳塊高亮
* 改進導出塊引用
* 改進拖曳塊到資料庫高亮
* 關係圖節點不再顯示備註
* 移除 Unicode PUA 字元

### 修復缺陷

* 反向連結關鍵字高亮不正確
* 清理雲端倉庫失敗
* 刪除某些塊後撤銷異常

### 開發重構

* 升級至 Mermaid v11.4.0
* 升級 flowchart.js v1.18.0
* 升級 pdfcpu v0.9.1
* 升級 FSRS v3.3.0

### 開發者

* 相容於設定程式碼塊最大高度後的換行行為
* 改進內核 API `/api/block/getBlockKramdown`
* 支援由 `updateProtyleToolbar` 傳回的工具列配置熱鍵
* 內核在路徑 `/caldav/` 提供 CalDAV 服務
