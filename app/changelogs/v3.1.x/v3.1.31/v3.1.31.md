## Changelogs

Below are the detailed changes in this version.

### Enhancement

* Open the Explorer window in the foreground
* Improve find-replace
* Improve block ref dynamic anchor text and database primary key anchor text update
* Improve the inline element settings
* Update the `parent_id` of blocks below a heading block when updating the heading block
* Improve outline jump positioning
* Improve database asset field value adjustment sorting
* Support local image links with parameters

### Bugfix

* Block refs and block hyperlinks jump to the embed block
* Enabling the authorization code on Android may result in a black screen
