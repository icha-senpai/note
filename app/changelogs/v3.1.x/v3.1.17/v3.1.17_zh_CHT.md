## 概述

此版本降低了啟用同步時的啟動時間。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 資料庫綁定塊主鍵支援設定靜態錨文本
* 貼到資料庫中的文字支援使用 `\t` 和 `\n` 進行分割和換行
* 在 macOS 上調整介面縮放時的視窗按鈕
* 行動資料庫總是顯示 `計算` 行
* 改進屬性面板 - 資料庫 - 刪除塊
* 改進清單項目多選縮排互動
* 移除瀏覽器預設的 Ctrl+B/I/U
* 啟用同步時減少啟動時間

### 修復缺陷

* Linux 上不顯示表情符號
* 貼到資料庫導致崩潰
* 使用查詢語法搜尋時結果未高亮顯示
* 文件無法匯出為 Markdown
* 匯出的 PDF 中清單項目樣式不正確
* 無法在行動裝置上匯出資料

### 開發重構

* 升級至 AWS SDK for Go v2
* 升級至 Electron v32.2.7

### 開發者

* 為 Protyle 新增 `renderAVAttribute` 方法
* 新增外掛程式 `getAllModels`
