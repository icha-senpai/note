## 概述

此版本修复了一些缺陷，并改进了很多细节，其中比较重要的是改进了数据同步、文档树和反链面板。

## 变更记录

以下是此版本中的详细变更。

### 改进功能

* 改进表格中多选单元格后的复制和剪切
* 当关键字索命中不同的块内容时返回文档块
* 改进表格单元格选择
* 多选数据库条目的右键菜单支持更多复制选项
* Markdown 语法开关不再影响剪贴/粘贴 HTML 解析
* 文件历史支持调整项目列表宽度
* 文档树支持多个文档在同一个新窗口中打开
* 数据库资源字段的本地资源支持 `重命名`
* 图片标题支持换行
* 拖动文件时指示插入位置
* 数据库单元格支持垂直拖动以填充值
* 改进文档树移动及其动画
* 改进 S3/WebDAV 数据同步配置
* 发布服务不再支持导出
* 在数据历史预览区域显示文档标题
* 改进导入 Markdown 时解析 `<img>`
* 改进导入 Markdown 时解析 YAML Front Matter
* 改进 HTML 剪藏
* 比较数据快照时支持所有纯文本格式
* 改进大纲面板加载性能
* 改进数据同步稳定性
* 改进集市网络可用性
* 改进数据同步感知
* 改进反向链接面板
* 动态加载图节点和边
* 改进外观菜单

### 修复缺陷

* 文档树创建时间和更新时间颠倒
* 链接的 `清除行级元素` 行为异常
* 切换外观语言后集市语言不变
* 为行级标签添加块引用异常
* 大纲/书签面板无法显示项目
* Linux 上 OCR 功能无法正常使用

### 开发重构

* 升级 Electron v32.2.2
