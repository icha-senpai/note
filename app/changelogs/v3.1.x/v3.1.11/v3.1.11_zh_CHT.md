## 概述

此版本修復了一些缺陷，並改進了許多細節，其中比較重要的是改進了資料同步、文件樹和反鏈面板。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 改進表格中多重選取儲存格後的複製與剪下
* 當關鍵字索取不同的塊內容時返回文件塊
* 改進表格儲存格選擇
* 多選資料庫項目的右鍵選單支援更多複製選項
* Markdown 語法開關不再影響剪貼/貼上 HTML 解析
* 文件歷史支援調整項目清單寬度
* 文檔樹支援多個文件在同一個新視窗中開啟
* 資料庫資源欄位的本機資源支援 `重命名`
* 圖片標題支援換行
* 拖曳文件時指示插入位置
* 資料庫儲存格支援垂直拖曳以填滿值
* 改進文檔樹移動及其動畫
* 改進 S3/WebDAV 資料同步配置
* 發布服務不再支援匯出
* 在資料歷史預覽區域顯示文件標題
* 改進導入 Markdown 時解析 `<img>`
* 改進導入 Markdown 時解析 YAML Front Matter
* 改進 HTML 剪藏
* 比較資料快照時支援所有純文字格式
* 改進大綱面板載入效能
* 改善資料同步穩定性
* 改善市集網路可用性
* 改進資料同步感知
* 改進反向連結面板
* 動態載入圖節點與邊
* 改進外觀選單

### 修復缺陷

* 文件樹建立時間與更新時間顛倒
* 連結的 `清除行級元素` 行為異常
* 切換外觀語言後集市語言不變
* 為行級標籤新增塊參考異常
* 大綱/書籤面板無法顯示項目
* Linux 上 OCR 功能無法正常使用

### 開發重構

* 升級 Electron v32.2.2
