## 概述

該版本改進了一些細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 改良頁籤拖曳
* 改進在超級塊中建立新塊
* 範本彈出視窗支援拖曳預覽區域大小
* 資料庫主鍵錨文本支援換行
* 改進設定介面
* 在行動裝置上編輯時停用左右滑動彈出側欄面板
* 支援本機檔案系統同步與備份
* 新增取消超級方塊和切換到水平/垂直佈局的快捷鍵
* 改進在行級公式中加入備註
* 改善鴻蒙系統的支援
* 移除 S3/WebDAV 雲端同步目錄設定的 `新增` 和 `移除` 按鈕
* 改進搜尋高亮
* 支援忽略新增 Microsoft Defender 排除項目的提示
* 改進資料庫關聯和匯總樣式
* 改進搜尋 OCR 影像預覽區域定位
* 改進包含空格的關鍵字的查找替換
* 在 Android 上申請相機權限時彈出用途說明
* 改進右鍵塊選擇
* 改進資料庫資源欄位彈出視窗
* 改進微信公眾號文章剪藏

### 修復缺陷

* `Shift+Enter` 在塊內不執行軟換行
* 匯出範本時正確轉義查詢嵌入塊腳本
* 任意檔案刪除漏洞
* 設定 - 編輯器 - 字型在 macOS 上顯示亂碼
* 載入某些字型檔案導致內核崩潰

### 開發者

* 新增發布二進位訊息廣播的內核 API
* 新增透過 SSE 訂閱廣播訊息的內核 API
