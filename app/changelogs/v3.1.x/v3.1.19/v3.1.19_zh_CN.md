## 概述

此版本改进了一些细节。

## 变更记录

以下是此版本中的详细变更。

### 改进功能

* 改进页签拖动
* 改进在超级块中创建新块
* 模板弹出窗口支持拖动预览区域大小
* 数据库主键锚文本支持换行
* 改进设置界面
* 在移动设备上编辑时禁用左右滑动弹出侧栏面板
* 支持本地文件系统同步和备份
* 添加取消超级块和切换到水平/垂直布局的快捷键
* 改进在行级公式中添加备注
* 改进对鸿蒙系统的支持
* 移除 S3/WebDAV 云同步目录设置的 `添加` 和 `移除` 按钮
* 改进搜索高亮
* 支持忽略添加 Microsoft Defender 排除项的提示
* 改进数据库关联和汇总样式
* 改进搜索 OCR 图像预览区域定位
* 改进包含空格的关键字的查找替换
* 在 Android 上申请相机权限时弹出用途说明
* 改进右键块选择
* 改进数据库资源字段弹出窗口
* 改进微信公众号文章剪藏

### 修复缺陷

* `Shift+Enter` 在块内不执行软换行
* 导出模板时正确转义查询嵌入块脚本
* 任意文件删除漏洞
* 设置 - 编辑器 - 字体在 macOS 上显示乱码
* 加载某些字体文件导致内核崩溃

### 开发者

* 添加发布二进制消息广播的内核 API
* 添加通过 SSE 订阅广播消息的内核 API
