## 概述

該版本改進了一些細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 從空白段落塊中刪除零寬空格
* 改良預覽樣式
* 改進市集包載入
* 支援表格多選儲存格複製純文字
* 使用 html-to-image 替換 html2canvas
* 改進塊選單中的寬度子選單
* 改進清單塊的塊標渲染位置
* 字體大小支援相對設定
* 尋找替換後合併相同元素
* 改進大綱跳轉定位
* 輸入後有外觀的文字保持其外觀
* 縮放後固定浮動視窗
* 在 iOS 上切換應用程式後改進重新連線提示
* 行動端資源選單中的「匯出」改為呼叫瀏覽器下載
* 改進行動端的元素選單
* 改進圖表編輯渲染
* 改進建立引用子文件時錨文本轉義
* 市集搜尋多個關鍵字使用 AND 邏輯
* 改進塊引用動態錨文本新增行級樣式
* 某些情況下不顯示塊標
* 資料庫支援在儲存格結尾按 `Tab` 建立新條目
* 複製資料庫儲存格並貼上到文件標題中僅貼上純文字
* 改進資料庫多重選取和關聯欄位儲存格彈出編輯
* 透過箭頭鍵改進資料庫儲存格或彈出選項的切換
* 改進瀏覽器剪藏擴充功能
* 改進包含表情符號的內容的資料庫欄位排序
* 改進浮窗編輯內容同步
* 改進「移動」自動填入搜尋關鍵字
* 改進行級元素的 Ctrl+X
* 支援按回車鍵進入子選單
* 改進行級公式的「最佳化排版」
* 支援在 Harmony NEXT 上顯示伺服 IP
* 改進回溯文件以避免 ID 重複
* 在將文件轉換為標題/移動塊之前產生文件歷史記錄
* 改進從 Claude 貼上公式
* 資料庫資源欄位支援鍵盤操作
* 改進查詢嵌入塊自動刷新
* 市集插件包更新後重新啟動插件
* 行動端支援資源設定

### 移除功能

* 不再支援 Android 7
* 不再支援 iOS 14

### 修復缺陷

* 刪除行級元素結尾異常
* 全域搜尋後閃卡管理會被錯誤亮起來
* 貼上嵌入塊後出現異常
* 行動端裝置上無法長按貼上
* 無法貼上從 WPS 複製的特定文字
* 插件自訂的 URL 連結不起作用
* 匯出為 PDF 時超級塊中的公式塊未完全顯示

### 開發重構

* 重構大綱函數 setCurrentById 的滾動策略
* 升級至 Electron v34.3.3

### 開發者

* 改進內核 API `/api/filetree/getPathByID`
* 插件 API 支援透過塊 ID 開啟塊屬性面板
* 行動端返回導覽時缺少 `switch-protyle` 或 `loaded-protyle-static` 事件
* 新增內核 API `/api/block/batchUpdateBlock`
