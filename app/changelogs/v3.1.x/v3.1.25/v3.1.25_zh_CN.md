## 概述

此版本改进了一些细节。

## 变更记录

以下是此版本中的详细变更。

### 改进功能

* 从空段落块中删除零宽空格
* 改进预览样式
* 改进集市包加载
* 支持表格多选单元格复制纯文本
* 使用 html-to-image 替换 html2canvas
* 改进块菜单中的宽度子菜单
* 改进列表块的块标渲染位置
* 字体大小支持相对设置
* 查找替换后合并相同元素
* 改进大纲跳转定位
* 输入后带有外观的文本保持其外观
* 缩放后固定浮动窗口
* 在 iOS 上切换应用后改进重新连接提示
* 移动端资源菜单中的“导出”改为调用浏览器下载
* 改进移动端的元素菜单
* 改进图表编辑渲染
* 改进创建引用子文档时锚文本转义
* 集市搜索多个关键字使用 AND 逻辑
* 改进块引用动态锚文本添加行级样式
* 某些情况下不显示块标
* 数据库支持在单元格末尾按 `Tab` 创建新条目
* 复制数据库单元格并粘贴到文档标题中仅粘贴纯文本
* 改进数据库多选和关联字段单元格弹出编辑
* 通过箭头键改进数据库单元格或弹出选项的切换
* 改进浏览器剪藏扩展
* 改进包含表情符号的内容的数据库字段排序
* 改进浮窗编辑器内容同步
* 改进“移动”自动填充搜索关键字
* 改进行级元素的 Ctrl+X
* 支持按回车键进入子菜单
* 改进行级公式的“优化排版”
* 支持在 Harmony NEXT 上显示伺服 IP
* 改进回滚文档以避免 ID 重复
* 在将文档转换为标题/移动块之前生成文件历史记录
* 改进从 Claude 粘贴公式
* 数据库资源字段支持键盘操作
* 改进查询嵌入块自动刷新
* 集市插件包更新后重启该插件
* 移动端支持资源设置

### 移除功能

* 不再支持 Android 7
* 不再支持 iOS 14

### 修复缺陷

* 删除行级元素末尾异常
* 全局搜索后闪卡管理会被错误高亮
* 粘贴嵌入块后出现异常
* 移动端设备上无法长按粘贴
* 无法粘贴从 WPS 复制的特定文本
* 插件自定义的 URL 链接不起作用
* 导出为 PDF 时超级块中的公式块未完全显示

### 开发重构

* 重构大纲函数 setCurrentById 的滚动策略
* 升级到 Electron v34.3.3

### 开发者

* 改进内核 API `/api/filetree/getPathByID`
* 插件 API 支持通过块 ID 打开块属性面板
* 移动端返回导航时缺少 `switch-protyle` 或 `loaded-protyle-static` 事件
* 添加内核 API `/api/block/batchUpdateBlock`
