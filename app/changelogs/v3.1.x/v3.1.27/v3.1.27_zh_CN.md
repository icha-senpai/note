## 概述

此版本改进了一些细节。

## 变更记录

以下是此版本中的详细变更。

### 改进功能

* 分屏文档保持相同的浏览位置
* 支持在 iOS 端内购功能特性和年付订阅
* 视频播放器在 Android 上支持全屏
* 改进文档树排序
* Android 端工具栏被软键盘遮挡
* 改进跨窗口拖动页签
* 光标在向上移动到以 \n 结尾的块时落在错误的位置
* Android 端上横屏模式下全屏显示
* 改进模板中块引用锚文本的渲染
* 剪藏扩展增加一个配置项以在剪藏后展开文档树
* 在移动端的搜索结果列表中显示标签
* 在块引用前的块末尾按 Delete 键不会移动光标
* 改进资源文件重命名
* 改进设置搜索
* 重命名或删除标签不再重新加载界面
* 改进网页剪藏
* 新增模板函数 `getBlock`
* 改进页签拖动的视觉效果
* 改进 Markdown 图片输入解析
* 改进列表中超链接后的回车解析
* 改进软换行粘贴解析
* 修剪日记块引用/新文档保存路径中的前后空格
* 调整列表下段落块和代码块的样式
* 改进嵌入块更新
* 改进在反向链接面板、聚焦和浮动窗口中取消超级块
* 改进断开行级代码、标签和键盘标记的快捷键
* 改进已安装市场插件 README 中本地图片的渲染
* 在粘贴 Markdown 时行级元素中的双引号不再转换为 HTML 实体
* 改进浏览器剪藏扩展
* 改进 #标签 搜索创建提示
* 改进搜索方式图标

### 修复缺陷

* 查找替换转义字符会丢失内容
* 引述块显示了额外的块图标
* 按 Delete 键引发的异常
* 编辑 mermaid/plantUML 无法正常工作
* 资源文件搜索未显示搜索结果列表
* 复制列表后移动会触发状态异常
* 某些情况下无法打开面板

### 开发者

* 新增内核内部 API `/api/ui/reloadAttributeView`
* 新增内核内部 API `/api/ui/reloadProtyle`
* 新增内核内部 API `/api/ui/reloadFiletree`
* 新增内核内部 API `/api/ui/reloadUI`
* 新增插件函数 `globalCommand`
