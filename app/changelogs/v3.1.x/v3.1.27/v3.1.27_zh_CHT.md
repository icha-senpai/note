## 概述

該版本改進了一些細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 分割畫面文件保持相同的瀏覽位置
* 支援在 iOS 端內購功能特性和年付訂閱
* 影片播放器在 Android 上支援全螢幕
* 改進文檔樹排序
* Android 端工具列被軟鍵盤遮擋
* 改進跨視窗拖曳頁籤
* 遊標向上移動到以 \n 結尾的方塊時落在錯誤的位置
* Android 端上橫螢幕模式下全螢幕顯示
* 改進範本中塊引用錨文本的渲染
* 剪藏擴充功能增加一個配置項目以在剪藏後展開文件樹
* 在行動端的搜尋結果清單中顯示標籤
* 在塊引用前的塊結尾按 Delete 鍵不會移動遊標
* 改進資源檔案重新命名
* 改進設定搜尋
* 重新命名或刪除標籤不再重新載入介面
* 改進網頁剪藏
* 新增範本函數 `getBlock`
* 改進頁籤拖曳的視覺效果
* 改進 Markdown 圖片輸入解析
* 改進清單中超連結後的回車解析
* 改良軟換行貼上解析
* 修剪日記塊引用/新文件儲存路徑中的前後空格
* 調整清單下方段落塊和程式碼塊的樣式
* 改進嵌入塊更新
* 改進在反向連結面板、聚焦和浮動視窗中取消超級塊
* 改進斷開行級程式碼、標籤和鍵盤標記的快捷鍵
* 改進已安裝市場插件 README 中本地圖片的渲染
* 在貼上 Markdown 時行級元素中的雙引號不再轉換為 HTML 實體
* 改進瀏覽器剪藏擴充功能
* 改進 #標籤 搜尋建立提示
* 改進搜尋方式圖示

### 修復缺陷

* 尋找替換轉義字元會遺失內容
* 引述塊顯示了額外的塊圖示
* 按 Delete 鍵引發的異常
* 編輯 mermaid/plantUML 無法正常運作
* 資源檔案搜尋未顯示搜尋結果清單
* 複製清單後移動會觸發狀態異常
* 某些情況下無法開啟面板

### 開發者

* 新增內核內部 API `/api/ui/reloadAttributeView`
* 新增內核內部 API `/api/ui/reloadProtyle`
* 新增內核內部 API `/api/ui/reloadFiletree`
* 新增內核內部 API `/api/ui/reloadUI`
* 新增外掛程式 `globalCommand`
