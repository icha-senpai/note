## 概述

該版本改進了一些細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 隱藏平板上的狀態列
* 改進表格儲存格選擇
* 改進在文件底部建立塊
* 改進 macOS 上的字體渲染
* 改進在資料庫中按下下箭頭鍵切換儲存格時的文件捲動
* 改進搜尋視窗拖曳
* 改進外掛程式加入 CSS
* 改進聚焦動畫
* 改進手機端上匯出圖片的寬度
* 改進嵌入塊更新
* 改進 Markdown 輸入解析
* 改進聚焦回傳 ID 不存在的情況
* 改進閃卡導入
* 在行動端的狀態列中顯示資料索引訊息
* 改進嵌入塊的插件相容性
* 改進行動端上的選單動畫
* 改進行動端上的麵包屑滾動和點擊
* 改進虛擬引用後的貼上連結
* 改良公式塊解析
* 改進 Markdown 超連結輸入解析
* 支援匯入 Markdown 時解析縮排程式碼塊語法
* 改進瀏覽器剪藏擴充功能

### 修復缺陷

* AI DeepSeek 422 Unprocessable Entity
* 行動端無法長按貼上
* 空塊中反向刪除異常
* WebDAV 清理資料倉儲失敗
* 套用樣式到塊引用導致其消失
* 無法開啟雲端標記快照

### 開發重構

* 升級至 Electron v34.3.4
