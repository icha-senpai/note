## 概述

## 变更记录

以下是此版本中的详细变更。

### 改进功能

* 隐藏平板上的状态栏
* 改进表格单元格选择
* 改进在文档底部创建块
* 改进 macOS 上的字体渲染
* 改进在数据库中按上下箭头键切换单元格时的文档滚动
* 改进搜索窗口拖动
* 改进插件添加 CSS
* 改进聚焦动画
* 改进移动端上导出图片的宽度
* 改进嵌入块更新
* 改进 Markdown 输入解析
* 改进聚焦返回 ID 不存在的情况
* 改进闪卡导入
* 在移动端的状态栏中显示数据索引消息
* 改进嵌入块的插件兼容性
* 改进移动端上的菜单动画
* 改进移动端上的面包屑滚动和点击
* 改进虚拟引用后的粘贴链接
* 改进公式块解析
* 改进 Markdown 超链接输入解析
* 支持导入 Markdown 时解析缩进代码块语法
* 改进浏览器剪藏扩展

### 修复缺陷

* AI DeepSeek 422 Unprocessable Entity
* 移动端无法长按粘贴
* 空块中反向删除异常
* WebDAV 清理数据仓库失败
* 应用样式到块引用导致其消失
* 无法打开云端标记快照

### 开发重构

* 升级到 Electron v34.3.4
