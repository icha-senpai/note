## 概述

這個版本支持了鴻蒙系統。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 改進 Alt+M 隱藏/顯示視窗
* 改進資料庫單元格定位和編輯輸入框大小
* 支援鴻蒙系統
* 貼上時移除折疊標題的折疊狀態
* 支援資料庫日期欄位少於 4 位元的年份
* 改進資料庫描述的互動
* 改進文件標籤添加互動
* 改進工具提示
* 改進導出塊引用
* 改進搜尋高亮
* 改進範本搜尋
* 改進匯出為 PDF 時的程式碼塊分頁
* 改進 HTML 剪藏
* 改進系統字體載入
* 產生包含 ' 字元的塊引用時導致奇怪的行為
* 簡化搜尋結果中的文件塊路徑
* 瀏覽器剪藏擴充功能加入了一些實驗性功能
* 屬性面板 - 資料庫支援移除目前塊
* 支援 flac 音訊資源播放
* 當圖像 URL 包含 `%` 時無法雙擊預覽
* 在 Linux 上使用滑鼠中鍵關閉標籤頁會觸發貼上
* 改進設定外觀優先權

### 修復缺陷

* 行動端資料歷史中的文件在下滑時會關閉
* 點選行級標籤後找不到結果
* HTML 標籤搜​​尋轉義問題
* 匯出至 .docx 的有序列表序號不正確
* 以 `.` 結尾的檔案名稱會被視為缺失資源
* 完全手動同步模式導致資料衝突

### 開發者

* 改進選擇塊或表格儲存格後 `Backspace` `Delete` `Tab` `Shift+Tab` 的操作
* 新增內核 API `/api/filetree/moveDocsByID`
* 移除編輯器輸入控制台日誌
* 為 Protyle 新增 `disable` 和 `enable` 方法
