## 概述

該版本改進了許多細節，並提升了效能和穩定性。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 持久化文檔樹展開狀態
* 改進資料庫拖曳時的視覺閃爍
* 瀏覽器剪藏擴充功能支援設定文件標籤
* 匯入 Markdown 檔案時解析 YAML 前置內容為文件自訂屬性
* 高亮顯示正規表示式搜尋結果
* 支援禁用 Markdown `*` 和 `_` 語法輸入
* 瀏覽器剪藏擴充支援路徑選擇
* 新增範本函數 `getHPathByID`
* 改進拖曳塊的互動效果
* 改進程式碼塊圖表貼上渲染
* 改進資料庫日期欄位貼上
* 改進資料庫關係和匯總欄位匯出
* 重做標題後自動刷新大綱
* 支援將單一標題和清單轉換為引用塊
* 改進嵌入塊的標題層級匯出
* 改進行級元素編輯
* 支援設定圖片高度
* 尋找替換後刷新結果清單
* 回溯文件後刷新其他關聯塊
* 尋找替換塊後刷新其他關聯塊
* 匯出壓縮包（如 Markdown 格式）時不再需要授權
* 改進資料庫塊/文字/資源/範本/關係/匯總欄位排序
* 回溯快照時預設為目前資料建立快照
* 載入畫面彈出訊息不再阻塞介面載入
* 新增或刪除嵌入塊後自動刷新參考計數
* 改進資料庫連結和資源欄位匯出
* 改進雲端資料同步穩定性
* 資料快照支援分頁導覽
* 國際化支持義大利文
* 文件歷史支援分頁導覽

### 修復缺陷

* 搜尋結果包含大小寫混合的文字元素時替換失敗
* 聚焦後分割畫面內容塊不同步
* 圖片設定為居中後無法透過選單調整寬度
* 更改表格儲存格中的文字元素後發生異常
* 無法設定閃卡 FSRS 權重
* 移動父親文檔後子文檔路徑未更新
* 某些 PDF 資源無法進行內容搜尋
* 點選關係圖中的文件標籤時報錯

### 開發重構

* 升級至 Electron v30.5.1

### 開發者

* 新增外掛事件 `opened-notebook` 和 `closed-notebook`
* 為塊選單的按鈕新增 `data-id` 屬性
* 改進 /選單
