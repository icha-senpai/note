## 概述

此版本修復了一些細節缺陷，建議升級。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 改進編輯器表情符號載入
* 改良 CSDN 剪藏
* 改進程式碼塊行號渲染
* 回溯文件後僅重新索引目前文件
* 改進分隔線輸入
* 不再限制編輯器中動態載入塊的數量
* 改良鏈滴剪藏
* 改進資料庫關聯欄位綁定/解綁塊

### 修復缺陷

* 改進清單項目編輯
* 程式碼塊中僅包含空格的行導致行號計算錯誤
* S3/WebDAV 無法取得雲端快照清單
* 匯出為 PDF/圖片/HTML 時程式碼塊未進行語法高亮

### 開發重構

* 升級至 FSRS-5

### 開發者

* 新增核心 API `/api/filetree/getPathByID`
* 修復 API `/api/asset/upload` 回應體 `succMap` 欄位
