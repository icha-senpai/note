## 概述

此版本改进了一些细节。

## 变更记录

以下是此版本中的详细变更。

### 改进功能

* 支持将标签替换为其他行级元素
* 改进表格行插入
* 打开开发者工具后底部侧边栏面板异常
* 标签重命名支持列出搜索候选项
* 浏览器剪藏扩展支持剪藏 SVG
* 支持列表块字体大小修改
* 平板上默认显示数据库块图标
* 改进导出 PDF 中公式块的间距
* 改进将引用块转换为段落后的撤销操作
* 升级集市包后重新加载 README
* 改进公式块解析
* 分屏文档保持相同的浏览位置
* 改进网页剪藏
* 标签搜索支持空格分隔的关键字
* 改进集市包更新验证
* 改进 Android 上的块引用跳转
* 减少删除/重命名标签时出现 `tree not found` 的概率
* 改进标签面板刷新
* 改进标题图片更新同步到其他窗口
* 改进表格中的软换行编辑
* 全局搜索支持制表符搜索
* 改进表格单元格包含 br 时的行级元素设置
* 解决自定义 ⌥⇧→/⌥⇧← 与原生快捷键冲突

### 修复缺陷

* 创建标签时内容异常
* 对已有背景色的文本重新应用相同背景色后异常
* Android 上插入图片或文件的按钮无法使用
* 打开搜索界面后编辑会导致界面重新加载
* Android 上所有 `导入` 按钮无法使用
* 移动端虚拟引用无法跳转
* 无法查找替换标签
* 在数据库绑定块中输入时光标位置不正确

### 开发重构

* 升级到 Electron v34.5.0

### 开发者

* 改进内核 API `/api/block/moveBlock` 的编辑器刷新
* 内核 API 请求无需设置访问授权码即可鉴权
* 改进数据同步后插件的重新加载
* 插件的全局快捷键无法再次绑定
* 新增内核内部 API `/api/ui/reloadTag`
