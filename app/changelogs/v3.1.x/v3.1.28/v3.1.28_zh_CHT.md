## 概述

該版本改進了一些細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 支援將標籤替換為其他行級元素
* 改進表格行插入
* 開啟開發者工具後底部側邊欄面板異常
* 標籤重新命名支援列出搜尋候選項
* 瀏覽器剪藏擴充支援剪藏 SVG
* 支援清單塊字體大小修改
* 平板上預設顯示資料庫塊圖示
* 改進匯出 PDF 中公式塊的間距
* 改進將引用塊轉換為段落後的撤銷操作
* 升級市集包後重新載入 README
* 改良公式塊解析
* 分割畫面文件保持相同的瀏覽位置
* 改進網頁剪藏
* 標籤搜尋支援空格分隔的關鍵字
* 改進市集包更新驗證
* 改進 Android 上的塊引用跳轉
* 減少刪除/重新命名標籤時出現 `tree not found` 的機率
* 改進標籤面板刷新
* 改進標題圖片更新同步到其他視窗
* 改進表格中的軟換行編輯
* 全域搜尋支援製表符搜尋
* 改進表格儲存格包含 br 時的行級元素設定
* 解決自訂 ⌥⇧→/⌥⇧← 與原生快速鍵衝突

### 修復缺陷

* 建立標籤時內容異常
* 對已有背景色的文字重新套用相同背景色後異常
* Android 上插入圖片或檔案的按鈕無法使用
* 開啟搜尋介面後編輯會導致介面重新載入
* Android 上所有 `導入` 按鈕無法使用
* 行動端虛擬引用無法跳轉
* 無法尋找替換標籤
* 在資料庫綁定塊中輸入時間標位置不正確

### 開發重構

* 升級至 Electron v34.5.0

### 開發者

* 改進內核 API `/api/block/moveBlock` 的編輯器刷新
* 核心 API 請求無需設定存取授權碼即可鑑權
* 改進資料同步後插件的重新載入
* 插件的全域快捷鍵無法再次綁定
* 新增內核內部 API `/api/ui/reloadTag`
