## 概述

此版本修復了一些細節缺陷，建議升級。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 改進在 PDF 矩形標註中貼上選定文本
* 改進離線時的市場載入
* 插入帶有 `allow-popups` 屬性的 IFrame 塊
* 改進 HTML details-summary 剪藏
* 改進行動端上的插件選單
* 改進刪除主題分隔線下方的空白塊
* 在程式碼塊中按 Tab 鍵不再取消選取內容
* AI 操作 `清除上下文` 不再關閉彈出視窗
* 改進 `Alt` 或 `Shift` 拖曳塊圖示
* 建立新文件後需要刷新視窗標題
* 改進匯出 HTML 的標題
* 潛在的資料匯出外洩安全漏洞
* 改進資料同步
* 改進資料庫表格視圖匯出
* 清單項目斷線不再影響資料庫綁定塊
* 改進 HTML 清單剪藏
* 改進在內嵌元素前後輸入 `&`
* 改進 HTML kbd 剪藏
* 改進插入/上傳時的資源檔案名稱規範化
* 改進資料庫文字欄位匯出
* 改進網頁剪藏適配

### 修復缺陷

* 資料庫搜尋鍵盤隱藏在 Android 上
* 任務清單中的文字刪除後仍有刪除線樣式
* 帶有 `\` 的虛擬引用解析錯誤
* `複製標題和底部塊` 在 Android 上無法正常運作
* 嵌入塊導出不正確
* 按 Tab 鍵後任務清單樣式不正確

### 開發重構

* 升級 Electron v30.4.0

### 開發者

* 更新程式碼塊的 DOM
* 為內核 API `/api/ref/getBacklinkDoc` 新增參數 `containChildren`
