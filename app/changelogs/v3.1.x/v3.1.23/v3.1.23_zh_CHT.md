## 概述

該版本改進了一些細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 資料庫整體居中或居右後無法點選項目塊標
* 隱藏嵌入塊中最後一個非文檔路徑的麵包屑文字
* 改進程式碼/鍵盤/標籤元素編輯
* 去重容器塊反向連結
* 改進表格和最近塊搜尋的定位
* `AI 編寫` 支援自訂快捷鍵
* 改進退出對焦後定位
* 改進關係圖面板全螢幕後視窗控制按鈕位置
* 改進資料庫主鍵表情的居中與換行
* 將多個文件拖曳到編輯器時插入清單參考
* 雙擊 .search__drag 恢復預設寬度
* 改進動態載入
* 改良 RTL 渲染
* 改進圖片/連結元素的查找替換
* 刪除文件標題中的 `<br>`
* 支援唯讀模式下複製表格
* 隱藏收集箱中的網路圖示
* 改進資料庫日期欄位相對過濾
* 從收集箱移動後展開文件樹
* 在表格內點選時隱藏工具列
* 僅在分享至社區時將引用轉換為純文本
* 改進反向提及高亮
* 改進屬性面板 - 資料庫中的連結開啟
* 改進瀏覽器剪藏擴充功能
* 改進塊引用計數刷新
* 改進選單貼上
* 切換內容塊 LTR RTL 佈局支援自訂快速鍵
* 改進標題塊複製和貼上
* 改進程式碼塊解析
* 改進導入 Markdown 時的資源 src 解碼
* 複製文件後展開文件樹
* 改進市集主題更新
* 在鴻蒙系統上將內核改為長時任務
* /選單新增鍵盤元素
* 支援透過環境變數設定授權碼
* 文件轉換標題後刷新虛擬引用快取
* 支援透過環境變數設定工作空間路徑和語言
* 回溯文件後更新大綱
* 改良外觀模式切換
* 貼上中間包含 `>` 的文字時不再建立引述塊
* 展開折疊的標題後顯示塊引用計數
* 改進包含轉義符的文字搜尋替換
* 插入資源檔案大小限制由 4G 調整為 8G

### 修復缺陷

* Windows 10 上的行級程式碼異常
* 屬性面板關聯欄位異常
* 錯誤的進程名稱
* 行動端缺少編輯 Mermaid 的入口
* 捲軸樣式不正確
* 匯入 Markdown 資料夾時相對路徑錯誤
* 行動文件後回溯文件異常
* macOS/Linux/Windows arm64 上未打包字型
* 網路影片無法下載
* `dragover__bottom` 類別名稱沒有移除

### 開發重構

* 升級至 Graphviz v3.11.0
* 升級至 Electron v33.4.1

### 開發者

* 改進內核 API `exportMdContent`
