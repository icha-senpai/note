## 概述

該版本改進了一些細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 行動裝置上的間隔重複介面不再顯示按鍵字母
* 改進 PDF 跨頁標註
* 改進表情符號與動態圖示樣式
* 相容搜狗輸入法智慧調整數字後的標點符號
* 瀏覽器剪藏擴充支援多語言
* 新增自適應寬度切換的快速鍵並將其新增至命令面板
* 改進資料庫條目選擇
* 改進搜尋跳轉聚焦塊然後退出聚焦定位
* 跨工作區拖曳塊不應被處理
* 支援在段落塊開頭插入 `￥￥` 將其轉換為公式塊
* 啟用同步時減少退出時間
* 當塊引用錨文本為空時使用 ID
* 改進退出時的更新檢查
* 改進 PDF 搜尋跳轉問題
* 在反向連結面板中顯示引用計數
* 新增字數統計模板函數 `runeCount` 和 `wordCount`
* 支援基於目前語言的 / 選單搜尋
* 支援一鍵新增 Microsoft Defender 排除項目
* 貼上內容到文件標題時去除 Markdown 標記
* 改進分割畫面合併超級塊

### 修復缺陷

* 一些與資料庫相關的問題
* 鴻蒙端升級時崩潰或白屏

### 開發者

* 升級至 highlight.js v11.11.1
