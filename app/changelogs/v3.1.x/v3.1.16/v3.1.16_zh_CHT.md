## 概述

該版本改進了一些細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 改進資料庫單元外觀
* 多重選擇清單項目在縮排或減少縮排後保持選取狀態
* 行動文件視窗保留上次搜尋的關鍵字
* 改進字體系列和表情符號
* 改進資料庫選擇欄位的顏色和佈局
* 改進貼上圖片後的遊標定位
* 資料庫主鍵欄位顯示綁定文件塊圖示
* 支援在行動裝置上尋找替換和資源檔案歷史
* 改進行級元素解析
* 允許在瀏覽器環境中使用面板中的 stickTab 圖示
* 新增塊內容統計範本函數 `statBlock`
* 改進文件標籤互動
* 改進啟用「在目前標籤頁中開啟」時的前進與後退
* 支援設定自動同步間隔
* 改進導入 Markdown 檔案
* 新增 SQL 查詢範本函數 `querySQL`
* 搜尋預覽區域支援行級備註定位
* 新增阿拉伯語支援
* 改進匯出資料
* 改進資源檔案載入效能
* 改善資料同步穩定性
* 相容圖片遺留資料
* 改進圖片的 `Del` 行為

### 移除功能

* 移除 Sentry 報告診斷資料

### 修復缺陷

* 大綱面板更新覆蓋內容問題
* 貼上程式碼塊缺少換行
* 回滾文件後編輯器未自動刷新
* 無法使用 `查詢語法` 搜尋
* 使用微軟拼音在資料庫搜尋中無法輸入中文字元
* 一些安全漏洞

### 開發者

* 推送更新塊 ID 事件
