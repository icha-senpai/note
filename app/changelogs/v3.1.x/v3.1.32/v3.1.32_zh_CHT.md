## 概述

該版本改進了一些細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 資料庫範本欄位支援透過 ID 存取
* 新增範本函數 `markdown2text` 和 `markdown2content`
* 改善因極端情況導致的段落塊不完整問題
* 資料庫範本欄位支援存取原始值
* 升級 mermaid.js 至 v11.6.0
* 改進輸入 `[[` 和貼上功能
* 改進標題下方的反向連結過濾
* 改進網路資源下載到本地的功能
* 尋找替換支援查詢語法
* 改進反鏈面板劃選
* 支援在瀏覽器中匯入 Markdown 壓縮包
* 當備註元素為空時清除備註元素

### 修復缺陷

* 無法在 HarmonyOS 上設定行級元素
* 修正 Linux 桌面匯出路徑選擇問題
* 在 Android 上塊引用重複
* 啟用發布服務基本認證後響應體為空指標
* 匯出預覽/HTML 可能遺失塊背景顏色
* 正規表示式搜尋在單引號情況下無效

### 開發重構

* 升級至 Electron v35.5.0
