## 概述

此版本改进了一些细节。

## 变更记录

以下是此版本中的详细变更。

### 改进功能

* 改进页签拖动高亮
* 当鼠标按在工具栏以外的元素上时隐藏工具栏
* 改进数据库主键、关联和汇总字段的内容转义
* 当超级块的所有子块被选中时，不支持合并为超级块
* 复制行级元素时移除 Markdown 标记符
* 支持复制图片文件后多次粘贴
* PDF 标注支持转换为文本
* 改进行级代码元素解析
* 改进块内容统计
* 改进列表超级块编辑
* 改进导入配置
* 改进下划线元素解析
* 避免窗口控件覆盖 Scribli 工具栏按钮
* 改进列表项、超级块和引用块的反向链接传递
* 支持通过网络伺服设置移动端代理
* 改进文档、大纲、数据库和块的拖动
* 文档块标题的反向链接计数包括子块
* 改进更改数据库字段类型
* 支持点击 PlantUML 图表超链接
* 改进浏览器剪藏扩展的懒加载图片处理
* 支持在 Android 上设置保活通知文本

### 开发重构

* 升级到 Electron v32.2.8

### 开发者

* 添加插件 API `openSetting`
* 更改插件 API `addFloatLayer` 的参数
