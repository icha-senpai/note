## 概述

該版本改進了一些細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 改良頁籤拖曳高亮
* 當滑鼠按在工具列以外的元素上時隱藏工具列
* 改進資料庫主鍵、關聯和匯總欄位的內容轉義
* 當超級塊的所有子塊被選中時，不支援合併為超級塊
* 複製行級元素時移除 Markdown 標記符
* 支援複製圖片檔案後多次貼上
* PDF 標註支援轉換為文字
* 改進行級程式碼元素解析
* 改進塊內容統計
* 改進清單超級塊編輯
* 改進導入配置
* 改進底線元素解析
* 避免視窗控制覆蓋 Scribli 工具列按鈕
* 改進清單項目、超級塊和引用塊的反向連結傳遞
* 支援透過網路伺服設定行動裝置代理程式
* 改進文件、大綱、資料庫和塊的拖曳
* 文件塊標題的反向連結計數包括子塊
* 改進更改資料庫欄位類型
* 支援點擊 PlantUML 圖表超連結
* 改進瀏覽器剪藏擴充功能的懶加載圖片處理
* 支援在 Android 上設定保活通知文字

### 開發重構

* 升級至 Electron v32.2.8

### 開發者

* 新增外掛程式 API `openSetting`
* 更改插件 API `addFloatLayer` 的參數
