## 概述

此版本改進了一些細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 改進 AI 編輯浮窗中的輸入框
* 塊引用候選項列表按最近引用排序
* Mermaid/圖表/公式編輯器支援顯示行號
* 改進行動端狀態列顏色解析
* 行動端瀏覽器上三星鍵盤彈出後立即收起
* 改進 iOS 上的速記
* 關閉視窗後在表格中輸入會導致文檔向上捲動
* 安全地呼叫 kernel.destroy
* 繼續擴大檔案樹中摺疊切換的點擊區域
* 在 iOS 上將速記註冊為 App 捷徑並整合 Siri
* 全新的內建文檔封面圖片
* 改進 Pad/平板大綱面板的捲動、拖曳和長按選單
* 改進貼上超連結的解析
* 新版面的 UI 改進
* 行動端觸碰列表項圖示時頁面不再捲動
* 停用「合併分頁到頂欄」後全螢幕按鈕錯位
* 嵌入區塊中的圖片寬度調整不會即時同步
* 在空列表項中輸入 `- ` 會導致轉譯異常
* 分享 URL 時思源應用未出現在 iOS 分享面板中
* 改進 Android 和 HarmonyOS 上的鍵盤彈出行為
* 行動端支援大綱拖曳
* 提高超級區塊內子區塊的拖曳寬度百分比精度
* 改進設定頁面樣式
* 改進超級區塊內列表區塊的拖曳
* 根據字型大小設定摺疊區塊的高度
* 統一對外 HTTP 請求的 User-Agent
* 透過 Docker 部署時瀏覽器中「複製為 PNG」無法使用
* 改進含合併儲存格的表格的複製貼上功能
* 改進資料庫虛擬捲動
* 針對不同字型大小調整列表項懸停樣式
* 改進選單捲動列
* 資料庫卡片檢視和看板檢視未顯示選取項數量
* 資料庫「切換顯示項圖示」忽略未綁定的區塊

### 修復缺陷

* 正常結束被誤報為連接埠監聽失敗
* 刪除包含掛件區塊的超級區塊時行為異常
* HarmonyOS 上其他應用無法將檔案分享到速記
* 速記同步後新建區塊狀態異常
* 多選區塊時若游標意外聚焦到嵌入區塊內則剪下失敗
* 行動端橫向超級區塊內巢狀區塊的 UI 版面異常
* 特定條件下列表項/引述/引用區塊內的刪除異常
* 在表格中編輯會重設捲動位置到表頭
* Microsoft Store 版本中的資料索引問題
* 撤銷標題展開後子區塊仍保持展開狀態
* 修復一些安全漏洞
* 行動端透過拖曳對文檔重新排序的問題
* 合併頂欄模式下分頁無法拖曳

### 文件

* 改進 CLI 安裝指南

### 開發重構

* 升級到 Electron v42.6.1
