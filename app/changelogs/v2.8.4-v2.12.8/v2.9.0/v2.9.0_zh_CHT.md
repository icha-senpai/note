## 概述

插件系統正式上線。

歡迎社區開發者參與插件開發，為思源筆記增加更多功能，從插件示例開始行動吧！

## 變更記錄

以下是此版本中的詳細變更。

### 引入特性

* 插件系統

### 改進功能

* 前端 API
* 頂欄按鈕支持取消固定
* 支持在 設置 - 資源 中列出缺失的文件
* iPhone 上禁用 Safari 後依然能夠打開瀏覽器
* 上傳云端快照索引時去重
* 改進 Pad 端設備檢測，將其作為桌面端
* 本地快照對比時添加更多文件格式支持
* 改進集市響應式界面
* 改進 Android 端后台喚醒後的界面響應
* 支持在文檔樹上打開文件歷史

### 移除功能

* 不再支持 Windows 7、8 和 Server 2012
* 移除 設置 - 外觀 - 系統原生文檔圖標

### 修復缺陷

* 移動端修改標題後進行後退錯誤覆蓋
* 集市包自述中的超鏈接無法在瀏覽器打開

### 開發重構

* 升級 Electron
* 移除依賴 electron-fetch

### 開發者

* 添加 `loaded-protyle` 到 eventbus
* 自定義文檔塊標菜單移到二級菜單中
* 插件 API `addTopBar` 參數 `icon` 必須為 svg id 或者 svg tag
