## v2.8.5 / 2023-04-18

### 改进功能

* 图片菜单添加 OCR 相关操作
* 在命名、别名等属性上 `Ctrl+Click` 打开搜索
* 改进在编辑器中复制自定义表情
* 间隔重复完成后支持选择继续
* 题头图支持拖拽放置
* 改进移动端编辑器设置
* Android 端支持返回键关闭弹出层
* 闪卡管理界面支持 ↑/↓ 选择
* 段落开头行级公式不再折叠渲染
* 间隔重复界面支持文档选择
* 移动端闪卡管理界面全屏
* 移动端数据同步目录显示最近更新时间
* 改进 PDF 资源文件未引用检测
* 导出 PDF 时资源文件不再使用 HTTP 伺服
* 优化文档树闪卡间隔重复加载性能
* 支持在编辑器右上角 `⋮` 菜单中删除文档
* 改进初始化界面中选择工作空间路径时的云盘检测提示
* 文档加载较慢时避免重复打开页签
* 在搜索对话框中支持通过 `Ctrl+N` 新建文档
* 改进通知消息换行显示
* `网络图片转换为本地图片` 时规范化文件名
* API `listDocsByPath` 添加可选参数 `maxListCount`
* 改进 HTML 块内容自动移除空行
* 改进快捷键设置在包含 `⌃` 时的处理
* 校验 API `moveBlock` 参数 `previousID` 的合法性
* 改进 HTML 块内容 `<div>` 标签匹配
* 支持通过 `((` 和 `[[` 进行块类型过滤
* 升级 abc.js 6.2.2
* 文件历史回滚后不再被数据同步覆盖
* ECharts 支持异步调用函数表达式（IIFE）
* 外观文案中将 `Bazaar` 更名为 `Marketplace`
* 调整设置界面左侧导航栏样式
* 支持在移动端编辑器只读模式下查看行级备注
* 新设备上同步时避免闪卡卡包数据覆盖云端

### 移除功能
