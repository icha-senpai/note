## 概述

如果你在旧版本中遇到了导出不完整或者文档动态加载不完整的情况，那么升级到此版本后应该就可以解决这些问题了。

### 即将不再支持 Windows 7、8 和 Server 2012

最后一个支持这些老旧系统的版本是下个版本 v2.8.10，以后发布的版本将不再支持 Windows 7、8 和 Server 2012，如有可能请尽快升级到 Windows 10 或更高版本。

## 变更记录

以下是此版本中的详细变更。

### 改进功能

* 支持弹出窗口拖拽位置和大小
* 支持块设置字体大小
* 按住 `Shift` 后鼠标悬浮块引用查看反链
* 社区集市上线一些插件
* 删除移动端调试信息 `Need remove unused code`
* 改进搜索结果在预览区的高亮和定位
* 挂件搜索支持符号链接
* 不再使用 quote 字体优化
* 支持导出 EPUB、ODT 和 RTF 时嵌入图片
* 改进 `粘贴` 和 `粘贴为纯文本`
* 云端收集箱支持移动到具体路径和复制内容
* 导入 Markdown 时不再使用 URL 编码超链接地址
* 点击编辑器时不再将光标移到链接、引用后
* 移动折叠标题时不再移动其他非折叠标题的下方块
* 下载插件后询问是否立即启用
* 改进桌面端初始化后主窗口的位置和大小
* 标签面板添加 `⋮` 菜单图标
* 添加内核 API `/api/file/renameFile`

### 移除功能

* 移除 Linux 端自动更新

### 修复缺陷

* 导出文档不完整
* 导入 .sy.zip 后自定义排序丢失
* 文档动态加载不完整
* 复制粘贴包含 `"` 的超链接时解析移除
* 在已有引用前后粘贴引用后不应该合并
* 移动端在某些情况下显示空白

### 改进文档

* 更新内核 API `insertBlock`
* 在用户指南中添加 最新进展 章节

### 开发者

* 改进插件 API `loadData`
* 插件 API `onunload` 未被调用
* 发布使用 Vite 和 Svelte 的插件样例模板库
* 内核 API `/api/file/*` 不再使用 HTTP 状态码
