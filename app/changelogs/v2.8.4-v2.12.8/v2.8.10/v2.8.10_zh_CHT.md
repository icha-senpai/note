## 概述

這是最後一個支持 Windows 7、8 和 Server 2012 的版本，升級到 Windows 10 或更高版本後才能使用後續版本的思源筆記。

### 🌐 英文論壇上線

Scribli 是思源官方英文論壇，歡迎大家前往交流。

後續我們會在思源 設置 - 賬號 中支持通過英文論壇賬號登錄，支持登錄後將開放非中國大陸地區的雲端數據同步和備份服務，敬請期待。

### 插件系統即將正式發布

我們將在下個版本 v2.9.0 中正式發布插件系統，歡迎大家基於該系統實現實用性和趣味性兼顧的插件。

這裡有一些插件相關的用戶需求，歡迎大家參考。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 搭建英文論壇
* 支持固定顯示表格的表頭
* 添加編輯器字號快速縮放開關
* 添加集市介紹頁
* 變更記錄支持繁體中文
* Linux 端 `version GLIBC_x.xx not found`
* 從 IDE 中粘貼代碼不再轉義 `<` and `>`
* 改進集市包繁體中文顯示
* 始終顯示窗口控制按鈕
* 文檔樹、反鏈、標籤和模板按字母排序時忽略大小寫
* 導入 Markdown 時支持 $ 後跟數字解析為公式
* 標題創建或刪除後更新大綱面板
* 自定義 Pandoc 路徑後工作空間不再重複初始化內置 Pandoc
* 優化獲取雲端快照性能
* 用戶指南中的文檔不再支持一鍵分享到社區
* 更新 `最近使用的外觀` 樣式
* 改進多塊 複製 - 重複 插入
* 改進插件加載性能
* 在移動端過拽看板時不再拉出側欄面板
* 粘貼 PDF 標註引用時移除非法字符

### 修復缺陷

* 搜索輸入框中無法選中文本
* 在新頁簽中打開間隔重複報錯
* 只讀模式下大綱定位不正確
* 在包含 `"` 的文本上粘貼引用或塊超鏈接解析異常
* 添加帶有樣式的塊為閃卡時沒有動畫
* 在表格中按 `F5` 不生效
* 行級公式顯示 `<wbr>`
* `Backspace` 刪除 Markdown 轉義符異常

### 文檔

* 在用戶指南中添加訂閱過期後刪除雲端存儲的詳細說明
* 在自述文件中添加架構設計章節

### 開發者

* 添加集市包配置項 `minAppVersion`
* 添加 `click-editortitleicon` 事件
* 為插件方法 `addTab` 添加 `Tab` 上下文
* 修復一些插件 API `addDock` 的缺陷
* 插件 API `Menu` 添加 `addItem` 以支持傳入 DOM 元素
* 刪除集市包配置項 `i18n`
* 插件 API `addDock` 支持序號和顯示選項
* 修復當頁簽不激活時為調用插件 API `addTab.init`
* 在 `eventBus` 中添加 `open-noneditableblock`
* 添加插件配置項 `backends` 和 `frontends`
* 改進插件系統設置交互
* 自定義塊標菜單移到二級菜單中
