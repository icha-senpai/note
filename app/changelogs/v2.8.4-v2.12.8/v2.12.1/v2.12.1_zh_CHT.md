## 概述

此版本支援配置忽略資料索引，並提升了雲端資料同步穩定性。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 支援忽略索引
* 當對話方塊超出視窗時重置對話方塊介面大小
* 題頭圖支援雙擊預覽
* 點選題頭圖時隱藏選單
* 視窗縮小時保持頁籤可見
* `後退` 保持滾動位置
* 新增資料庫表格視圖總列設定提示
* 根據閃卡配置顯示高亮標記
* 資料快照比較介面支援鍵盤選擇檔
* 為支援 `↑` 和 `↓` 的候選清單新增 `Home` 和 `End` 支援
* 切換應用程式後可能導致快速鍵失效
* 同一輪閃卡複習中不再顯示再次到期的卡片
* 改進 `新建文件存放位置`
* 移除嵌入塊中的圖片圖示選單
* 改良連續軟換行分塊解析
* 提升雲端資料同步穩定性

### 修復缺陷

* 某些 Emoji 圖示無法正常顯示
* 標題塊下方塊的父塊欄位計算不正確
* 開啟外部應用程式協議失效
* Alt+X 無法記錄字體顏色
* 無法直接預覽第一個範本
* 開啟文件後快速捲動導致定位重置

### 開發者

* 改進資料庫表格視圖 `單選` 值輸入
* 解決資料庫單選列、多選列和資源列無法批次操作
* 資料庫表格視圖單選框無法新增篩選條件
* 新增外掛程式 `lockScreen`
* 新增插件事件匯流排 `updateCards`
* 如果關聯列原記錄主鍵值為空則關聯列顯示 `Untitled`
* 修正插件建構子中無法存取 `name` 屬性的問題
* 資料庫塊支援匯出 CSV
* 資料庫表格視圖貼上值後不再重置滾動位置
* 資料庫範本列支援 `queryBlocks` 函數
* 新增內部核心 API `/api/filetree/upsertIndexes` 和 `/api/filetree/removeIndexes`
* 降低資料庫表格視圖新增行延遲
* 新增外掛程式 API `uninstall`
* 新增插件欄位 `protyleOptions`
* 改進排序的資料庫表格視圖新增行時的行為
* 新增內部核心 API `/api/repo/getRepoFile`
