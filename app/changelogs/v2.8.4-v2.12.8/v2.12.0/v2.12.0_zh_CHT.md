## 概述

此版本改進了內核穩定性，支援在匯出 PDF 和圖片時添加浮水印。

另外，從該版本開始 S3/WebDAV 資料同步和備份結束免費公測階段，後續需要付費才能使用，細節請訪問。

## 變更記錄

以下是此版本中的詳細變更。

### 引入特性

* 支援匯出 PDF 新增浮水印
* 支援匯出圖片新增浮水印

### 改進功能

* S3/WebDAV 資料同步與備份需要付費才能使用
* 改進 `行級程式碼` Markdown 編輯
* 改進 `//!js` 查詢嵌入塊結果排序
* 改進內核 API 請求並發控制
* 改進網頁剪藏內容轉換
* 改進行動端上開啟文件定位瀏覽位置
* 支援點選開啟形狀如 `www.foo.com` 的超連結
* 改進一些行級元素 Markdown 編輯
* 改良閃卡挖空樣式
* 改進複製到知乎時公式渲染
* 匯出 Markdown 時刪除行級公式中的換行
* 完整顯示 PDF 頁籤標題

### 修復缺陷

* 閃卡回到上一步重新複習後狀態不正確
* 行級備註與行級公式查找替換失效
* 無法匯出斜體的行級公式
* 某些情況下搜尋替換失效
* 唯讀模式下引用跳轉後未定位瀏覽位置
* 無法轉換外觀樣式的 PDF 註解引用為文字
* `Alt+F` 後快速按下評分快捷鍵失效
* 在嵌入塊中的圖片未能上傳社群

### 開發者

* 資料庫表格檢視新增總計欄位
* 新增外掛事件匯流排 `open-menu-inbox`
* 行動端切換停靠列異常
* 資料庫表格檢視資源列支援 Ctrl+V
* 資料庫表格視圖主鍵列支援 `[[` 綁定塊
* 改進內核 API `/api/notebook/*`
* 資料庫表格檢視支援在中間插入欄位
* 新增內部核心 API `/api/sqlite/flushTransaction`
* 新增外掛事件匯流排 `lock-screen`
* 改進資料庫開啟過濾時新增行操作
* 主鍵不再在屬性面板資料庫頁籤中顯示
* 資料庫視圖頁籤支援滾動
