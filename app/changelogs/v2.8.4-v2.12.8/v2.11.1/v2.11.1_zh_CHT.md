## 概述

此版本改進了雲端收集箱和微信小助手，歡迎體驗。

廣告： `功能特性` 早鳥價將於 2024 年 1 月初結束，如需購買請抓緊時間，細節請訪問。

註：`年付訂閱` 包含 `功能特性`，如果你是訂閱會員，則無需單獨購買功能特性。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 思源微信小助手轉換 amr 檔為 mp3 檔案
* 改進 Android 端軟鍵盤隱藏相容性
* 改進切換全域唯讀模式時編輯器閃爍
* 雲端收集箱移動到文件時自動下載網路資源檔案
* 改進雲端收集箱介面
* 雲端收集箱移動到文件時自動轉換 mp3 和 mp4 檔案為語音和視訊塊
* 雲端收集箱支援預覽語音和視訊
* 唯讀模式文件切換頁籤時不保留劃選內容
* 改進搜尋介面
* 改進匯出包含換行底線的圖片
* 改進匯出 Markdown 超連結空格
* 改善對話方塊和選單存在時浮動停靠列的互動
* 搜尋關鍵字歷史支援刪除
* 為行動端新增軟換行按鈕
* 為搜尋輸入框新增清空按鈕
* 改進 `行級程式碼` markdown 編輯

### 修復缺陷

* 清理資料倉儲錯誤 `清理資料倉儲失敗：CreateFile ...`
* `Ctrl+Tab` 在 Windows 端失效
* 雲端收集箱行動裝置文件時遺漏資料
* 匯出包含 `../` 超連結 Markdown 檔案系統異常
* `貼上轉義文字` 處理不正確
* 搜尋結果預覽包含轉義符問題

### 開發重構

* 升級 Electron v27.1.3

### 開發者

* 資料庫支援多視圖
* 改進資料庫表格視圖 `Tab` 鍵互動
* 為外掛程式 API 添加一些 `Protyle` 方法
* 當編輯器左側邊距最小時改進資料庫表格視圖行圖示
* 新增插件事件 `mobile-keyboard-show` 和 `mobile-keyboard-hide`
* 新增插件事件 `sync-start`、`sync-end` 和 `sync-fail`
* 插件 `requrie` 函數支援載入 node 模組
* 建立日記文件時新增 `custom-dailynote-yyyyMMdd` 屬性
* 新增一些日期相關的範本函數
