## 概述

此版本改進了一些細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 支援透過快捷鍵 `Ctrl+Shift+T` 重新開啟頁籤
* 在 macOS 上支援 `scribli://` 協定
* 改進介面佈局
* 改進大綱面板
* 改進 `最近的文件`
* 改進程式碼塊語言選擇
* 改進資料庫歷史
* 改進網頁無權限讀取剪貼簿時顯示的提示
* 改進鴻蒙端上的沉浸式體驗
* 改進折疊標題編輯
* 改進資料同步 S3 供應商相容性
* 改進 HTML 圖片剪藏
* 改進 HTML 數學公式剪藏
* 改進資料庫匯總和資源欄位過濾
* 當選擇閃卡塊時，塊選單顯示「移除閃卡」選項
* 改良複製塊內容的取消轉義
* 將多個選取塊複製為副本並插入到最後一個選取塊之後
* 支援在 Android 上呼叫系統列印
* 匯出 PDF 時為自訂頁邊距新增單位說明
* 改進匯出 HTML/PDF/圖片 時的 IFrame 處理
* 改進大綱中拖曳項目時的自動捲動
* 在行動端點選文件樹中的文件圖示將展開
* 支援在鴻蒙端上呼叫系統列印
* 點擊邊緣或空隙會導致遊標跳到開頭
* 改進 FSRS 權重初始化
* 超級塊下的嵌入塊支援顯示麵包屑
* 改進資料同步
* 改進清單項目編輯與拖曳
* 改進 S3 資料同步代理端點（Cloudflare Tunnel）
* 改進鴻蒙端 IP 清單取得
* 資料庫切換檢視支援撤銷和重做
* 改進文件匯出 HTML
* 改進資源檔案重複插入的檢測
* 行動端新增發布服務設定頁面

### 修復缺陷

* 鴻蒙端設定行級元素問題
* 修復若干閃卡問題
* 清單編輯觸發異常狀態
* 插件開關狀態未同步
* 重新命名文件標題未更新屬性中的 `title`

### 開發重構

* 升級至 Electron v37.7.1

### 開發者

* 在屬性中記錄某些 Protyle 元素的寬度
* 最佳化 Dockerfile 以最大化快取利用和並行性
* 改進 #commonMenu 選單
* 新增內核 API `/api/block/getBlockDOMWithEmbed` 和 `/api/block/getBlockDOMsWithEmbed`
