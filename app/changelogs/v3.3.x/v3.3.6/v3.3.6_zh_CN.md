## 概述

此版本改进了一些细节。

## 变更记录

以下是此版本中的详细变更。

### 改进功能

* 支持通过快捷键 `Ctrl+Shift+T` 重新打开页签
* 在 macOS 上支持 `scribli://` 协议
* 改进界面布局
* 改进大纲面板
* 改进 `最近的文档`
* 改进代码块语言选择
* 改进数据库历史
* 改进网页无权限读取剪贴板时显示的提示
* 改进鸿蒙端上的沉浸式体验
* 改进折叠标题编辑
* 改进数据同步 S3 提供商兼容性
* 改进 HTML 图片剪藏
* 改进 HTML 数学公式剪藏
* 改进数据库汇总和资源字段过滤
* 当选择闪卡块时，块菜单显示“移除闪卡”选项
* 改进复制块内容的取消转义
* 将多个选中块作为副本复制并插入到最后一个选中块之后
* 支持在 Android 上调用系统打印
* 在导出 PDF 时为自定义页边距添加单位说明
* 改进导出 HTML/PDF/图片 时的 IFrame 处理
* 改进在大纲中拖动项目时的自动滚动
* 在移动端点击文档树中的文档图标将展开
* 支持在鸿蒙端上调用系统打印
* 点击边缘或空隙会导致光标跳到开头
* 改进 FSRS 权重初始化
* 超级块下的嵌入块支持显示面包屑
* 改进数据同步
* 改进列表项编辑和拖拽
* 改进 S3 数据同步代理端点（Cloudflare Tunnel）
* 改进鸿蒙端 IP 列表获取
* 数据库切换视图支持撤销和重做
* 改进文档导出 HTML
* 改进对资源文件重复插入的检测
* 移动端新增发布服务设置页面

### 修复缺陷

* 鸿蒙端设置行级元素问题
* 修复若干闪卡问题
* 列表编辑触发异常状态
* 插件开关状态未同步
* 重命名文档标题未更新属性中的 `title`

### 开发重构

* 升级到 Electron v37.7.1

### 开发者

* 在属性中记录某些 Protyle 元素的宽度
* 优化 Dockerfile 以最大化缓存利用和并行性
* 改进 #commonMenu 菜单
* 添加内核 API `/api/block/getBlockDOMWithEmbed` 和 `/api/block/getBlockDOMsWithEmbed`
