## 概述

該版本支援了資料庫按字段分組並改進了大量細節。

請注意：

* 舊版無法開啟新版的資料庫，如果你使用的行動端是在商店安裝的，建議等商店上架新版本後再更新桌面端
* 資料庫範本的多選欄位值從字串變更為字串數組，請參考這裡進行適配

## 變更記錄

以下是此版本中的詳細變更。

### 引入特性

* 資料庫依欄位分組

### 改進功能

* 改進「加入資料庫」
* 改進資料庫欄位預設填入
* 資料庫匯總欄位支援使用範本欄位
* 閃卡為文件時顯示標題
* 改進資料庫塊綁定
* 改進匯出預覽模式 CSS 變數值填色
* 卡片視圖支援顯示欄位名稱
* 改進文件標題回車處理
* 提升大量內容貼上效能
* 改進自訂程式碼塊行號顯示
* 改善資料同步，避免因折疊塊導致的衝突
* 刪除塊時在某些情況下不再在文件開頭新增空塊
* 改進範本搜尋高亮
* 匯出預覽模式支援聚焦使用
* 匯出預覽時程式碼塊保留屬性
* 支援程式碼塊高亮模板語法並將程式碼塊範本匯出為段落
* 「重新 OCR」在 Tesseract 未啟用時彈出視窗提示
* 改進 `<br>` 輸入解析
* 更新 highlight.js 插件
* 改進卡片視圖顯示
* 改進狀態列索引建立資訊提示
* 改進標籤中表情符號的搜尋
* 文件支援複製為 Markdown
* 資料庫匯總欄位支援複製為副本
* 改進 HTML 剪藏
* 當 .sy 檔案或資料庫 .json 超過 8MB 時提醒使用者
* 限制資料庫標題為 512 個字元
* 「上傳資源檔案到雲端」支援聚焦使用
* 改進匯出 PDF 樣式
* 貼上時解析 `<img>` 標籤
* 資料庫範本欄位支援使用其他範本欄位
* 改進資料庫「垂直拖曳填充值」
* 標籤頁切換改進
* 瀏覽資料庫表格目前視圖圖片時過濾隱藏列
* 資料庫拖曳、效能與互動最佳化
* 資料庫篩選條件未進行篩選計算時移除高亮
* 改進資料庫範本欄位使用多重選取欄位
* 改進導入時 `<img>` 標籤解析
* 資料庫匯總欄位支援使用更新時間/建立時間欄位
* 手動最佳化資料索引以減少空間佔用並提升效能
* 改進資料庫屬性面板
* 退出折疊塊時改進聚焦定位

### 修復缺陷

* 資料庫選擇欄位若新增選項過快會遺失選項
* 取消超級塊時行內公式未渲染
* 從資源資料夾拖曳檔案到編輯器導致內核退出
* 新視窗鎖定後再進入會重複產生托盤
* 尋找替換會錯誤地將標籤轉換為文字
* 浮窗中將清單轉為段落塊後插入位置錯誤
* 公式相關編輯器狀態異常
* 資料庫匯總欄位篩選結果不正確

### 開發重構

* 升級至 Electron v37.3.1
