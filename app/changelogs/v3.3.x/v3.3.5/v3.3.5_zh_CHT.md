## 概述

該版本改進了一些細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 瀏覽器剪藏擴充功能支援右鍵選單「傳送到思源」
* 改進資料庫關聯欄位篩選設定
* 改進文件瀏覽位置載入
* 鴻蒙系統支援主題跟隨系統設定的明暗模式
* 改進間隔重複介面
* 搜尋結果顯示文件標題
* 改進工具列位置計算
* 改進折疊標題編輯
* 改進瀏覽器剪藏擴充功能「剪藏網頁後開啟文件」
* 增加行動裝置編輯工具列高度
* 資料庫塊新增「在資料夾中顯示」
* 唯讀模式支援預覽標題圖片和點擊文件標籤搜尋
* 改進搜尋文件標題高亮顯示
* 改進導出塊引用樣式
* 移除文件塊選單中的「導入」項目
* 網頁無剪貼簿讀取權限時提示
* 改進塊備註顯示
* 退出對焦並捲動至對應塊時取消動畫效果
* 搜尋輸入方塊關閉自動補全與拼字檢查
* 改進匯出含子文件的空白文檔
* 改進匯出 Markdown 塊引用相對路徑
* 「搜尋資源文件內容」和「匯出 PDF 或圖片加浮水印」由付費改為免費
* 改進複製和剪切
* 改進資料同步 S3 供應商相容性
* 改良 HTML img 剪藏

### 修復缺陷

* 清單中塊拖曳異常
* 行動端空列表項目插入圖片會插入到下一個段落塊
* 從文件樹開啟的文件資料庫屬性面板不顯示內容
* 更新程式碼後圖表未刷新
* 資料庫一直載入
* 設定 KaTeX 巨集定義後無法匯出 PDF
* 無法儲存搜尋和替換類型設定

### 開發者

* API `getTag` 新增選用參數 `ignoreMaxListHint`
* 新增核心 API `/api/ui/reloadIcon`
* 改進唯讀模式下多選塊後 `click-blockicon` 事件觸發
