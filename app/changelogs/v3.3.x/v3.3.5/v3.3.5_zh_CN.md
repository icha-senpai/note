## 概述

此版本改进了一些细节。

## 变更记录

以下是此版本中的详细变更。

### 改进功能

* 浏览器剪藏扩展支持右键菜单“发送到思源”
* 改进数据库关联字段筛选设置
* 改进文档浏览位置加载
* 鸿蒙系统支持主题跟随系统设置的明暗模式
* 改进间隔重复界面
* 搜索结果显示文档标题
* 改进工具栏位置计算
* 改进折叠标题编辑
* 改进浏览器剪藏扩展“剪藏网页后打开文档”
* 增加移动端编辑工具栏高度
* 数据库块新增“在文件夹中显示”
* 只读模式支持预览标题图片和点击文档标签搜索
* 改进搜索文档标题高亮显示
* 改进导出块引用样式
* 移除文档块菜单中的“导入”项
* 网页无剪贴板读取权限时提示
* 改进块备注显示
* 退出聚焦并滚动到对应块时取消动画效果
* 搜索输入框关闭自动补全和拼写检查
* 改进导出含子文档的空文档
* 改进导出 Markdown 块引用相对路径
* “搜索资源文件内容”和“导出 PDF 或图片添加水印”由付费改为免费
* 改进复制和剪切
* 改进数据同步 S3 提供商兼容性
* 改进 HTML img 剪藏

### 修复缺陷

* 列表中块拖拽异常
* 移动端空列表项插入图片会插入到下一个段落块
* 从文档树打开的文档数据库属性面板不显示内容
* 更新代码后图表未刷新
* 数据库一直加载
* 设置 KaTeX 宏定义后无法导出 PDF
* 无法保存搜索和替换类型设置

### 开发者

* API `getTag` 新增可选参数 `ignoreMaxListHint`
* 新增内核 API `/api/ui/reloadIcon`
* 改进只读模式下多选块后 `click-blockicon` 事件触发
