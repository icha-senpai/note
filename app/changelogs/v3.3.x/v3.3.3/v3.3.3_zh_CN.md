## 概述

此版本改进了一些细节。

## 变更记录

以下是此版本中的详细变更。

### 改进功能

* 数据库资源字段支持筛选
* 块引用元素导出时保留原有样式
* 折叠标题后新建的块为同级标题
* 增加标题展开与折叠的场景
* 移动文档后刷新界面数据
* 改进复制/剪切/删除 `标题与下方块` 菜单
* 提升数据库分组视图性能
* 将 mermaid.js 从 11.6.0 升级到 11.11.0
* 浏览器剪藏扩展支持“路径搜索时目录优先显示”
* 改进关闭笔记本后重新打开的交互
* 新增图标：iconInclude
* Microsoft Store 支持 arm64 版本
* 改进数据库菜单渲染
* 改进图表和数学编辑对话框的拖拽
* 数据库汇总字段支持使用关联字段
* 数据库汇总字段计算中增加“显示唯一值”
* 桌面端界面等待内核启动时间延长
* 导出 Markdown 行内代码时尽量去除末尾零宽空格
* 改进 HTML 代码块剪藏
* 改进 HTML 剪藏 base64 图片
* 改进数据库汇总复选框字段
* 数据库关联字段不允许编辑未绑定块的图标
* 改进数据库交互细节
* 在代码块开头使用退格键时改进交互
* 数据库关联字段支持复制已有关联
* 改进字体加载
* 改进打开文档兼容性
* 改进文档动态加载，防止特定情况下持续自动加载
* 改进可编辑块的判断和 HTML 块的转义处理

### 修复缺陷

* 编辑器切换时光标未跟随
* 数据库属性面板更新选择字段后，点击其他选择字段无响应
* 数据库日期字段启用“默认填充创建时间”后自动填充的时间值不正确
* 移动端数据库关联和汇总字段菜单未显示关联数据库名和字段名
* 导出图片时代码块行号显示为 0
* 文件历史无法加载数据库块的正确视图
* 代码块包含 ``` 时“优化排版”异常
* “添加到数据库”会显示不在文档中的数据库
* 鼠标点击插入标签时报错
* 大纲拖动功能异常

### 开发者

* 为面包屑解锁/锁定按钮标签增加属性
