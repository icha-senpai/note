## 概述

此版本改进了一些细节。

## 变更记录

以下是此版本中的详细变更。

### 改进功能

* 折叠标题的复制/剪切改为复制/剪切 `标题及其下方块`，并支持多标题复制/剪切
* 改进数据库字段编辑菜单
* 数据库汇总字段筛选规则支持“任一”、“所有”和“没有”
* 改进闪卡
* 数据库中新建数据如果在折叠分组内，不再弹出编辑框
* 代码块选择复制时仅复制纯文本
* 代码块语言提示搜索内容为空时使用默认排序
* 改进数据库汇总字段筛选
* 改进数据库日期字段筛选
* 数据库添加选项时禁止编辑
* 数据库条目跨分组拖动后，同步更新其他视图中的分组
* 浏览器剪藏扩展支持剪藏页面到数据库
* Android 隐藏底部手势导航栏
* 提升数据库分组视图性能
* 拖入多个文件到编辑器不再被默认程序打开
* 改进 HTML 表格剪藏
* 点击无文档的笔记本时自动新建文档
* 代码片段新增字段 `disabledInPublish`，用于标识发布服务中是否禁用

### 修复缺陷

* PDF 文件名过长无法生成标注图片
* 视频块网络地址不正确
* 数据库日期字段无法粘贴 0 点时间
* 预览模式下无法设置只读模式
* 批量插入文件到编辑器时异常
* 部分输入法在块末尾粘贴链接后标点符号重复插入

### 开发者

* 集市插件包元数据新增字段 `disabledInPublish`，用于标识发布服务中是否禁用
* 新增插件函数 `expandDocTree`
* 改进内核 API `appendBlock`、`insertBlock` 和 `prependBlock`
