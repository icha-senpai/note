## 概述

該版本改進了一些細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 折疊標題的複製/剪切改為複製/剪切 `標題及其下方塊`，並支援多標題複製/剪切
* 改進資料庫欄位編輯選單
* 資料庫匯總欄位篩選規則支援「任一」、「所有」和「沒有」
* 改良閃卡
* 資料庫中新建資料如果在折疊分組內，不再彈出編輯框
* 程式碼塊選擇複製時僅複製純文字
* 程式碼塊語言提示搜尋內容為空時使用預設排序
* 改進資料庫匯總欄位篩選
* 改進資料庫日期欄位篩選
* 資料庫新增選項時禁止編輯
* 資料庫條目跨分組拖曳後，同步更新其他檢視中的分組
* 瀏覽器剪藏擴充功能支援剪藏頁面到資料庫
* Android 隱藏底部手勢導覽列
* 提升資料庫分組檢視效能
* 拖入多個檔案到編輯器不再被預設程式開啟
* 改進 HTML 表格剪藏
* 點選無文件的筆記本時自動新建文件
* 程式碼片段新增欄位 `disabledInPublish`，用於識別發佈服務中是否已停用

### 修復缺陷

* PDF 檔名過長無法產生標註圖片
* 影片塊網路網址不正確
* 資料庫日期欄位無法貼上 0 點時間
* 預覽模式下無法設定唯讀模式
* 批次插入檔案到編輯器時異常
* 部分輸入法在塊末尾貼上連結後標點符號重複插入

### 開發者

* 集市插件包元資料新增欄位 `disabledInPublish`，用於識別發布服務中是否已停用
* 新增外掛程式 `expandDocTree`
* 改進內核 API `appendBlock`、`insertBlock` 和 `prependBlock`
