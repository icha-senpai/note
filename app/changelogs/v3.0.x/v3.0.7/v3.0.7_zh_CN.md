## 概述

此版本修复了一些影响常规使用的缺陷。

## 变更记录

以下是此版本中的详细变更。

### 改进功能

* 导出 PDF 添加水印不再被图片覆盖
* 编辑引用时不显示浮动窗口
* 改进数据库模板空日期渲染
* 文档标题支持 `粘贴为纯文本`
* 拖动大纲时生成文档历史
* `↓` 支持跳转到行尾
* 改进块引用搜索 ID 提取

### 修复缺陷

* 大纲拖动功能异常
* 数据库关联字段排序异常
* 移动端侧边栏自动隐藏
* 数据库汇总字段计算遗漏空值
* 调整列宽后最后一行未对齐
* 无法回滚文档历史
