## 概述

該版本修復了一些缺陷並改進了許多細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 瀏覽器剪藏擴充隱藏令牌明文
* 改進包含 iframe 的塊的拖曳和選擇
* 改進行動端底部狀態列
* 改進資料庫表格視圖行/列拖放排序
* 新視窗中的連結使用瀏覽器開啟
* 提示未正常退出
* 拖曳資料庫列時編輯器不應捲動
* 改進 `複製 文本*`
* 支援以其他元素取代文字元素
* 改進資料庫匯總過濾
* 編輯資料庫表格檢視中的連結時選擇所有文字
* 資料庫日期過濾器排除空值
* 改進資料庫多重選取欄位排序
* 在已儲存的版面配置中新增更新日期
* 資料庫表格檢視中的自訂圖示不再變形
* 改進 HTML 解析程式碼塊
* 當資料庫範本欄位報告錯誤時提示
* 限制標籤面板中列出的標籤的最大數量
* 支援在資源列中開啟 Scribli 協定連結
* 改進 `Ctrl+Click` 選擇/取消選擇塊
* 改進行動端上資料庫輸入時的滑動
* 改進資料庫匯總欄位設定
* 改進更新資料庫表格檢視中的欄位的互動
* 資料庫中未綁定的行支援 `新增至資料庫`
* 當提及展開數設定為 0 時提及面板不應關閉
* 更改市集安裝包逾時為 2 分鐘

### 修復缺陷

* 調整鏡像資料庫的列寬度會影響其他視圖
* 嵌入塊中的資料庫介面顏色異常
* 資料庫新建欄位時選單位置不正確
* 在資料庫中新增行後無法立即編輯主鍵
* 關係圖刷新無效
* `移動` 塊後反向連結面板錯誤
* 資料庫解綁塊導致條目被刪除
* 列表項目下表格內刪除列後無法輸入

### 改進文檔

* 改進使用者指南格式化元素和快速鍵章節

### 開發者

* 在插件的 `Custom` 類別中新增 `editors`
