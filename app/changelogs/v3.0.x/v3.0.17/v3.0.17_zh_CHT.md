## 概述

此版本支援了 Windows arm64 和 Linux arm64，改進了網頁剪藏，修復了一些缺陷並改進了許多細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 支援拖曳停靠列圖示
* 改進查詢條件空輸入的處理
* 為 Linux 新增 deb 發布套件
* 在行動裝置上顯示資料庫角標
* 在唯讀模式下停用 `Ctrl+D`
* 改進 HTML h 剪藏
* 改進 HTML strong 剪藏
* 支援 Windows arm64
* 支援 Linux arm64
* 改進導入 Markdown 資料夾
* 改進在一些行級元素附近貼上
* 改進文件檔案歷史的回溯
* 在清單中調整影像大小後改進 `Enter` 縮排
* 改進反向連結面板中的塊折疊圖示按鈕
* 為 `恢復預設版面配置` 新增確認對話方塊
* 改進未命名文件佔位符
* 瀏覽器擴充支援維基百科公式剪藏
* 當存在多個視窗時不再重複開啟使用者指南
* 改進程式碼塊中的貼上
* 在 Windows 上改進 `向下/向上展開` 快捷鍵
* 改良 HTML img 剪藏
* 改進 HTML 公式剪藏
* 不剪下維基百科標題旁的 `編輯` 元素
* 改進任務清單重做
* 新增內部核心 API `/api/av/appendAttributeViewDetachedBlocksWithValues`
* 為 Linux 桌面端核心進行靜態編譯
* 在匯入 .sy.zip 時改進資料庫處理
* 改進表格解析

### 修復缺陷

* 微軟商店版版本的設定 - 關於異常
* PWA 檔案的請求沒有 `Authentication` 標頭
* 資料庫面板的主鍵排序在某些情況下失敗
* `優化排版` 導致清單中的 HTML 塊失效
* 在某些情況下無法重新排序資料庫條目

### 改進文檔

* 新增日文使用者指南
