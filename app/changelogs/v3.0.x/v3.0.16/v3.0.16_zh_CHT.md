## 概述

這個版本改進了網頁剪藏、修復了一些缺陷並改進了許多細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 擴大拖曳分割畫面的判斷區域
* 文件浮窗支援 `在新頁籤中開啟`
* 改進市集介面
* 改進知乎回答的瀏覽器擴充功能片段
* 改進在清單中按退格鍵後的遊標位置
* 字體大小和代碼 Tab 空格設定在行動裝置上改為選擇
* 改進文字、表格列和水平佈局的方向
* 改進複製資料庫塊
* 改良 HTML a 與 img 剪藏
* 匯出資料庫所在文件時匯出綁定塊文件
* 支援資料庫資源圖片複製貼上
* 改進資料庫文字、郵件、URL 和電話欄位內容的轉義
* 在預覽模式下使用真實主題樣式值替換變數
* 支援透過 `#` 觸發標籤選擇
* 改進內核穩定性
* 改為級備註導出
* 支援設定 `取消分割畫面` 和 `取消全部分螢幕` 快速鍵
* 改進快捷鍵搜尋
* 資料同步後刷新單一文件的唯讀狀態
* 改進 HTML strong 剪藏
* 改進大綱面板中的拖曳
* 改進程式碼片段搜尋
* 資料庫中的關鍵字搜尋邏輯從 OR 改為 AND
* 改進全域搜尋類型排序
* 改進連結懸浮提示樣式
* 改進 HTML 程式碼塊剪藏
* 改進瀏覽器擴充 HTML img 剪藏
* 塊引用跳轉後短暫高亮目標塊
* 改進 Ctrl+F 開啟搜尋對話方塊
* 改進資料庫關聯欄位過濾

### 移除功能

* iOS 上不再支援開啟使用者指南
* 匯出公式時不再展開巨集定義
* 微軟商店版不再支援應用程式內更新檢查

### 修復缺陷

* 雲端設定匯出的壓縮套件在重新命名後無法匯入
* HTML 塊內容轉義不正確
* 使用 `F3` 建立引用文件時行級程式碼渲染錯誤
* 新增行號欄位後資料庫最後一行未對齊
* 聚焦後拖曳文件異常
