## 概述

此版本支持数据库表格视图内搜索。

## 变更记录

以下是此版本中的详细变更。

### 改进功能

* 支持数据库表格视图内搜索
* 为 `人工智能` 添加快捷键
* 导入 Markdown 后不再刷新整个界面
* 移动端支持点击虚拟引用
* 社区集市支持根据仓库名搜索
* 改进数据库过滤存在时添加行的提示
* 字体大小大于 17 时图片下方不再出现空行
* 改进数据库 `创建时间` 和 `更新时间` 字段过滤
* 改进数据库排序存在时添加行的提示
* 改进数据库关联和汇总块时的浮窗
* 改进代码块界面
* 改进数据库模板字段更新延迟
* 改进 人工智能 API 设置交互
* 支持通过浮窗列出镜像数据库块
* 数据库块角标支持显示数据库标题
* 为 `添加至数据库` 添加快捷键
* 根据主窗口大小自动调整 PDF/Word 导出预览窗口大小
* 数据库表格视图日期字段添加默认值
* 仅在启动后自动校验一次数据索引
* 改进只读模式下数据库表格视图界面
* 改进 `跳转到下一个页签` 和 `跳转到上一个页签`
* 数据库 .json 遵循文档树单行保存设置
* 记录访问授权登录失败日志

### 修复缺陷

* 行尾连续空格异常
* 数据库过滤具体日期失效
* 修改字段类型后数据库过滤失效
* 数据库关联字段值未显示对应行
* 插入本地资源文件后会被自动打开

* 改进用户指南模板片段章节
