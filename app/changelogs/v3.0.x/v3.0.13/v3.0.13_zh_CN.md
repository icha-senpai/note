## 概述

此版本修复了一些缺陷并改进了很多细节。

## 变更记录

以下是此版本中的详细变更。

### 改进功能

* 支持在移动端使用一些快捷键
* 在文档树中选择多个文档时，右键菜单中添加 "打开" 选项
* 支持在导出数据库时渲染行号列
* 为块导航添加两个快捷键
* 调整 PDF 导出页脚字体大小
* 改进删除图片功能
* 支持在剪藏 HTML 时转换 Base64 图片
* 国际化支持日语
* 设置数据库表格视图中模板列编辑文本区的最大高度
* 改进数据库表格视图的删除操作
* 允许在 "关联" 字段中引用当前数据库
* 数据库搜索框支持在只读模式下粘贴
* 改进数据库表格视图中清除搜索按钮
* 当数据库创建双向关系时，同步相关条目
* 在生成资源文件历史时忽略隐藏文件
* 改进 HTML code 元素剪藏

### 修复缺陷

* Shift+↓ 无法扩展折叠列表的选择
* 浏览器/平板在加载界面时卡住
* 笔记本设置文档保存路径在某些情况下不会覆盖全局设置
* PDF 注解引用无法跳转
* 包含符号链接时无法导出 Data
* 在 Linux 桌面端上最大化窗口后界面崩溃
* 双击数据库资源列会导致界面卡住
* 集市 - 已下载 - README 中的包大小为空
* 在移动设备上点击超链接不会打开浏览器
* 复制图片并粘贴后文件名编码异常
* 数据库表格视图多选列快速选择异常
* 某些情况下绑定块后的新数据库条目会丢失
* 卸载挂件后数据同步未清空挂件文件夹

### 开发重构

* 降级到 Electron v28.3.1

### 开发者

* 为 `item.direction` 设置默认值
