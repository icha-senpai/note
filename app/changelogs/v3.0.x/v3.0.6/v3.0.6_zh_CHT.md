## 概述

該版本支持在大綱面板中拖拽調整大綱項的級別和位置。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 大綱面板中的大綱項支持拖動調整級別和位置
* 改進移動端上的圖片點擊交互
* 數據庫表格視圖主鍵支持粘貼引用塊
* 上下翻頁時留兩行空間
* 改進數據庫表格視圖 URL 字段顯示
* 打開文檔並加載了第一個塊時不再提示 "不要驚慌...上下滾動即可加載更多內容"
* 在思源窗口未聚焦時數據庫行的左選項難以選擇
* Android 端支援透過其他應用程式開啟圖片
* 改進標籤菜單抖動問題
* 改進數據庫表格視圖多選交互
* 支持搜索代碼片段
* 改進退出聚焦定位
* `隱藏/顯示窗口`支持配置`Alt+Fn`
* `隱藏/顯示窗口`僅適用於工作區
* 改進數據庫多字段排序中空值的處理
* 改進集市包界面
* 在數據庫表格視圖行菜單中點擊添加行
* 當塊未找到時自動從文件系統加載和索引
* 在閃卡菜單中添加 `新窗口打開`
* 拖動並插入文件夾時提示
* 支持編輯保存的佈局
* 改進數據同步衝突生成
* 數據歷史支持在所有筆記本中查詢
* 改進數據歷史的多語言
* 數據庫匯總支持數字計算
* 改進網頁剪藏表格解析
* `Ctrl+Home` 在文檔處於只讀模式時無法工作
* 在其上選擇文本時不應打開超鏈接
* 數據庫模板在使用匯總時支持數字計算
* 改進只讀模式下的引用和 PDF 引用光標樣式
* 改進複製純文本
* 改進數據庫匯總數字計算

### 修復缺陷

* 在只讀模式下禁用數據庫表格視圖列的右鍵菜單
* 按 Enter 後行級公式無法顯示
* 面包屑 XSS
* 輸入 /``` 後編輯器解析異常
* 在數據同步之前不應進行索引修復
* 新窗口全屏閃卡按鈕無法點擊
* 從嵌入塊進入浮動窗口 `Enter` 異常
* 屬性面板 - 數據庫 模板自定義屬性未顯示
* 包含 HTML 塊時導出 PDF 異常
* 數據庫塊複製文本*異常

### 開發者

* 移動端提供插件事件總線 `switch-protyle`
* 改進內核 API Token 校驗
