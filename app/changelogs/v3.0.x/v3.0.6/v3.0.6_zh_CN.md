## 概述

此版本支持在大纲面板中拖拽调整大纲项的级别和位置。

## 变更记录

以下是此版本中的详细变更。

### 改进功能

* 大纲面板中的大纲项支持拖动调整级别和位置
* 改进移动端上的图片点击交互
* 数据库表格视图主键支持粘贴引用块
* 上下翻页时留两行空间
* 改进数据库表格视图 URL 字段显示
* 打开文档并加载了第一个块时不再提示 "不要惊慌...上下滚动即可加载更多内容"
* 在思源窗口未聚焦时数据库行的左选项难以选择
* Android 端支持通过其他应用打开图片
* 改进标签菜单抖动问题
* 改进数据库表格视图多选交互
* 支持搜索代码片段
* 改进退出聚焦定位
* `隐藏/显示窗口`支持配置`Alt+Fn`
* `隐藏/显示窗口`仅适用于工作区
* 改进数据库多字段排序中空值的处理
* 改进集市包界面
* 在数据库表格视图行菜单中点击添加行
* 当块未找到时自动从文件系统加载和索引
* 在闪卡菜单中添加 `新窗口打开`
* 拖动并插入文件夹时提示
* 支持编辑保存的布局
* 改进数据同步冲突生成
* 数据历史支持在所有笔记本中查询
* 改进数据历史的多语言
* 数据库汇总支持数字计算
* 改进网页剪藏表格解析
* `Ctrl+Home` 在文档处于只读模式时无法工作
* 在其上选择文本时不应打开超链接
* 数据库模板在使用汇总时支持数字计算
* 改进只读模式下的引用和 PDF 引用光标样式
* 改进复制纯文本
* 改进数据库汇总数字计算

### 修复缺陷

* 在只读模式下禁用数据库表格视图列的右键菜单
* 按 Enter 后行级公式无法显示
* 面包屑 XSS
* 输入 /``` 后编辑器解析异常
* 在数据同步之前不应进行索引修复
* 新窗口全屏闪卡按钮无法点击
* 从嵌入块进入浮动窗口 `Enter` 异常
* 属性面板 - 数据库 模板自定义属性未显示
* 包含 HTML 块时导出 PDF 异常
* 数据库块复制文本*异常

### 开发者

* 移动端提供插件事件总线 `switch-protyle`
* 改进内核 API Token 校验
