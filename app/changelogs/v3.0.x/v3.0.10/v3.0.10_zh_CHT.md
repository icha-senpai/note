## 概述

此版本改進了資料索引和資料庫視圖相關細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 資料庫遊標焦點不再自動重置到標題輸入框
* 改進資料庫資源欄位編輯
* 改進設定字體大小後資料庫表格視圖介面
* 右鍵輸入輸入框提供複製選單
* 資料庫中綁定的塊支援 `新增至資料庫`
* 資料庫過濾選項值支援搜尋
* 改善市集載入效能
* 編輯文件時改進資料索引效能
* `Ctrl+Shift+F` 不再疊加關鍵字
* 改良行動裝置上的左右滑動
* 改進在程式碼、標籤和鍵盤之前 `Del`
* 導入 .sy.zip 與 markdown 時改善資料索引效能
* 改進匯出行級程式碼 markdown 元素
* 避免前端要求等待處理
* 改進預設搜尋類型過濾
* 建立文件時改進資料索引效能
* 移除連結、音訊和其他 URL 的拼字檢查
* 新增資料庫 `行號` 欄位類型
* 改進行動應用程式外觀語言設定
* 改進資料庫範本欄位計算
* 改進資料庫解綁塊
* 改進資料庫勾選方塊欄位排序
* 透過塊圖示選單選擇刪除後，塊圖示選單將不再顯示
* 改進資料庫範本欄位使用關聯/匯總欄位
* 禁止在嵌入塊中編輯資料庫檢視
* 改進資料庫引用錨文本
* 改進標題拖曳轉換文件子標題等級
* 改進資料庫欄位排序
* 改進資料庫綁定文件塊的更新時間

### 修復缺陷

* 資料庫日期欄位間過濾計算錯誤
* 選取資料庫行後貼上檔案報錯
* 開啟大綱後版面異常
* "清除樣式"後不應顯示程式碼塊行號
* 超連結影響反向連結計算問題
* 動態載入導致清單顯示不完整
* 資料庫新增行時主鍵值意外更新
* 在浮動浮窗中編輯資料庫新建一行時浮窗消失
