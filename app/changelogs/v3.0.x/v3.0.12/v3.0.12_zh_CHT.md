## 概述

此版本支援指定筆記本儲存新文件。

另外，預設禁用了一些行級元素的 Markdown 語法輸入，例如 `^`、`~`、`#` 和 `$`，如需啟用，請在 設定 - 編輯器 中調整。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 支援指定筆記本儲存新文件
* 搜尋類型設定區分容器塊和葉子塊
* 屬性面板 - 資料庫支援貼上資源檔案
* 改進文件圖示、背景和標籤編輯互動
* 主鍵欄位變更後資料庫關係欄位跟隨變更
* 改進磁碟使用顯示
* 改進超連結解析
* 改進行動裝置資料同步後刷新
* 標題塊轉換文件塊盡可能保留符號
* 改進 HTML 程式碼塊解析
* 文檔樹支援 `新增至資料庫`
* 改進市集包 README 渲染
* 資料同步產生衝突文件後刷新文件樹
* 支援停用某些行級元素的 Markdown 語法輸入
* 支援在 Windows 端上自動啟動後最小化主視窗
* 改進資料庫多重選取欄位排序
* 改進 HTML 剪藏
* 使用 `<sup>`/`<sub>` 匯出 Markdown 上標/下標
* 透過 `<sup>`/`<sub>` 支援輸入上標/下標
* 支援 `Alt+,` 開啟超連結
* 新增範本函數 `FormatFloat`
* 建立新文件後文件樹顯示焦點
* 建立文件後第一個塊不再反白
* 允許使用者指定 abcjsParams
* 透過 `Alt+Enter` 支援快速插入折疊清單項目的末尾子項
* 支援配置 `Ctrl+PageDown` 快捷鍵
* 改進市集
* 預設不在 HTML 塊中執行腳本以防止 XSS
* 使用總出現次數計算反向連結提及
* 文件處於唯讀模式時右鍵連結彈出式選單
* 改為級公式輸入
* 改進背景圖片上傳按鈕的遊標
* 資料歷史 - 檔案歷史 - 資源支援 `update` 操作索引
* 改進市集載入
* 支援 graphviz 自適應

### 修復缺陷

* 點選沒有連結的行級公式報錯
* 軟換行編輯解析異常
* S3/WebDAV 資料備份失敗
* 建立資料庫後無法立即輸入標題
* 修復嵌入塊的索引任務
* 某些提示快捷鍵不遵循設定
* 集市計數錯誤
* Alt 快捷鍵衝突
* 只能搜尋到第一個嵌入塊
* 資料歷史 - 檔案歷史 - 資源搜尋結果與操作條件不符
* 正規表示式搜尋替換導致段落嵌套

### 開發重構

* 升級至 Electron v30.0.1

### 開發者
