## 概述

此版本支援列出失效的塊引用，行動端支援拍照插入，資料庫日期欄位支援「相對於今天」過濾。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 支援在搜尋對話方塊中列出失效的塊參考
* 資料庫塊支援指定視圖
* 改進資料庫視圖切換
* 資料庫日期欄位支援相對於今天的過濾
* 在移動到選擇閃卡文件後不再彈出鍵盤
* 改良行動端橫屏時的閃卡複習介面
* 改進頁籤限制設定
* 改進行動端 `退出應用程式` 按鈕樣式
* 匯出資料庫塊時使用目前視圖設定的篩選和排序
* 改進行動裝置文件樹展開按鈕區域
* 支援隱藏資料庫表格視圖標題
* Android 端支援拍照插入圖片
* 限制 KaTex 巨集最大遞歸解析深度為 16
* 資料庫表格視圖存在過濾時新增行不再填入預設值
* 取消引用後自動刷新文件引用計數

### 修復缺陷

* 文件標題重新命名導致錨文本轉義異常
* 搜尋類型 "資料庫" 無法儲存
* 無法透過路徑搜尋影片、音訊塊
* 無法設定 Azure OpenAI
* 對話方塊中的全螢幕編輯器在 Esc 後無法拖曳視窗
* 資料庫表格視圖刪除數字值後排序異常
* Alt+O 大綱大小拖曳後編輯器右側空白
* 大綱寬度太小時無法調大

### 開發重構

* 降級 Electron v28.2.4

### 開發者

* 核心 API `/api/block/transferBlockRef` 新增參數 `reloadUI`
* 資料庫表格視儲存格值新增 `createdAt` 和 `updatedAt` 欄位
* 行動端新增 `protyleSlash`
