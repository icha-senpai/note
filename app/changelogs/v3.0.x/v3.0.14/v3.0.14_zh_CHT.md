## 概述

該版本修復了一些缺陷並改進了許多細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 最佳化包含關聯欄位的資料庫的渲染效能
* 改進資料庫文字、電子郵件、URL 和 電話欄位內容的轉義
* 改進反向連結面板提及擴充配置
* 提高程式碼塊的自適應性
* 複製時不隱藏錯誤訊息
* 刪除標籤、程式碼和鍵盤行級元素時清除零寬空格
* 改進 `加入資料庫` 的排序
* 改進連結提示
* 改進編輯器預覽
* 改進 HTML 程式碼塊剪藏
* 啟用過濾器時改進資料庫自動填充值
* 改進資料歷史提示
* 在唯讀模式下，可以編輯新檔案
* 改進行級公式的 `優化排版`
* 改進 HTML a 元素剪藏
* 改進瀏覽器剪藏擴充功能
* 改進塊上的選擇文字
* 支援唯讀模式下的資料庫表格檢視載入更多
* 資料庫屬性面板不再顯示行號欄位
* 改進日文翻譯與主題字體渲染
* 改進點擊、雙擊和輸入的多語言支援
* 改進文件樹更新時間顯示
* 支援唯讀模式下的 Alt+點擊
* 在唯讀模式下貼上資料庫表格視圖的頭部和底部
* 改進斜線選單
* 禁用標籤語法後不再支援透過 `#` 觸發標籤選擇
* 改進動態捲軸
* 改進嵌入/引用塊重建索引
* 改進表格最後一行 `Enter`
* 支援取消與目前資料庫相關的雙向關聯
* 改進兩個影像連接時的遊標
* 支援在行動裝置上與文件同步的大綱反白
* 改進雙向關聯欄位名佔位符
* 改進 `顯示VIP圖示`
* 改進 HTML 行級程式碼元素剪藏
* 改進匯出預覽模式
* 標題下方塊編輯後刷新標題塊更新時間

### 修復缺陷

* 貼為連結時，`:`後的 URL 內容遺失
* 在資料庫中建立新條目後無法立即建立新文件
* 資料庫無法連續刪除條目
* 卸載插件後資料同步未同步卸載
* 與目前資料庫相關時，雙向關聯無效
* 搜尋中的 `將網路資源轉換為本地` 無法刷新
* 折疊標題被剪切後撤銷異常
* 列出的標籤最大數量不正確
* HTML 塊內容轉義不正確
* 建立新的子文件後無法折疊父親文件
* 資料庫表格檢視連續在上方新增一行錯誤
* 資料同步後塊屬性不刷新
* 在程式碼塊的最後一行刪除後撤銷異常
* 重複開啟筆記本導致引用計數增加

### 改進文檔

* 改進使用者指南
