## 概述

此版本支持一键升级已下载的集市包。

## 变更记录

以下是此版本中的详细变更。

### 改进功能

* 支持一键升级已下载的集市包
* 优化文档移动和重命名性能
* 搜索类型过滤支持音频、视频、挂件和 IFrame 块
* 改进聚焦块导出时引用转换脚注
* 单击资源文件时使用默认程序打开
* 无法在 `---` 后回车
* Android 端支持使用其他应用打开资源文件
* AI 支持配置随机性和上下文数
* 改进只读模式下数据库表格视图
* 数据库单选字段按选项设置顺序排序
* 复制 PDF 矩形注解时不再重复插入图片
* 数据库表格视图支持一次性添加多行
* 移除 AI 菜单中的翻译部分以简化菜单
* 反链面板中不再会选择到面包屑
* `未引用资源` 支持复制文件名
* 改进数据库表格视图拖拽填充
* 改进动态加载文档后的返回操作
* 块 `复制纯文本` 后光标丢失
* 支持复制表格到数据库表格视图中
* 创建日记模板支持设置文档属性
* 搜索结果内容片段返回更多文本
* 改进导出 PDF 窗口
* 改进数据库表格视图资源字段界面
* 资源文件链接元素光标悬浮提示更多信息
* 创建文档时本地化标题
* 创建数据库后默认添加单选字段
* 改进 属性面板 - 数据库 编辑光标样式
* 改进拖拽文档内容时的光标样式
* 在 属性面板 - 数据库 中删除字段时进行提示
* 改进闪卡更多菜单界面

### 修复缺陷

* 移动端无法切换工作空间
* 属性面板 - 数据库 中出现重复的关联值
* 无法搜索替换超链接锚文本
* 无法搜索替换代码块中的 `{{foo}}`
* 行尾元素后软换行会丢失换行
* md 代码块中剪切时将 `<foo>` 误转换为 `&lt;foo&gt;`

### 开发重构

* 重构块折叠属性

### 开发者

* 支持 plugin.docks 配置快捷键
* 改进类型定义 `Scribli.config`
* 为 API `fetchSyncPost` 的 `data` 添加 `FormData` 类型
