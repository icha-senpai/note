## 概述

此版本支援一鍵升級已下載的市集包。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 支援一鍵升級已下載的市集包
* 最佳化文件移動與重新命名效能
* 搜尋類型過濾支援音訊、視訊、掛飾和 IFrame 塊
* 改進聚焦塊匯出時引用轉換註腳
* 點擊資源檔案時使用預設程式開啟
* 無法在 `---` 後回車
* Android 端支援使用其他應用程式開啟資源檔案
* AI 支援配置隨機性與上下文數
* 改進唯讀模式下資料庫表格檢視
* 資料庫單選欄位依選項設定順序排序
* 複製 PDF 矩形註解時不再重複插入圖片
* 資料庫表格檢視支援一次新增多行
* 移除 AI 選單中的翻譯部分以簡化選單
* 反鏈面板中不再會選擇到麵包屑
* `未引用資源` 支援複製檔名
* 改進資料庫表格視圖拖曳填充
* 改進動態載入文件後的回傳操作
* 塊 `複製純文字` 後遊標遺失
* 支援複製表格到資料庫表格檢視中
* 建立日記範本支援設定文件屬性
* 搜尋結果內容片段返回更多文字
* 改進匯出 PDF 視窗
* 改進資料庫表格視圖資源欄位介面
* 資源檔案連結元素遊標懸浮提示更多資訊
* 建立文件時在地化標題
* 建立資料庫後預設新增單選欄位
* 改進 屬性面板 - 資料庫 編輯遊標樣式
* 改進拖曳文件內容時的遊標樣式
* 在 屬性面板 - 資料庫 中刪除欄位時進行提示
* 改進閃卡更多選單介面

### 修復缺陷

* 行動端無法切換工作空間
* 屬性面板 - 資料庫 中出現重複的關聯值
* 無法搜尋替換超連結錨文本
* 無法搜尋替換程式碼塊中的 `{{foo}}`
* 行尾元素後軟換行會遺失換行
* md 程式碼塊中剪切時將 `<foo>` 誤轉換為 `&lt;foo&gt;`

### 開發重構

* 重構塊折疊屬性

### 開發者

* 支援 plugin.docks 配置快捷鍵
* 改進類型定義 `Scribli.config`
* 為 API `fetchSyncPost` 的 `data` 新增 `FormData` 類型
