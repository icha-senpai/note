## 概述

此版本正式發布資料庫表格視圖特性，所有使用者均可使用。

## 變更記錄

以下是此版本中的詳細變更。

### 引入特性

* 資料庫表格檢視

### 改進功能

* Azure OpenAI 人工智慧支援
* 支援自訂人工智慧請求標頭 User-Agent
* 支援自訂人工智慧模型
* 改進清單換行互動
* 支援持久化保留大綱面板展開狀態
* 改進標籤清單和帳號重繪按鈕

### 修復缺陷

* 行級元素設定異常
* 新視窗全螢幕後麵包屑無法點選
* 行級元素嵌套編輯異常

### 開發重構

* 升級 mermaid v10.8.0

### 開發者

* 新增內部核心 API `/api/block/appendDailyNoteBlock`
