## 概述

此版本正式发布数据库表格视图特性，所有用户均可使用。

## 变更记录

以下是此版本中的详细变更。

### 引入特性

* 数据库表格视图

### 改进功能

* Azure OpenAI 人工智能支持
* 支持自定义人工智能请求标头 User-Agent
* 支持自定义人工智能模型
* 改进列表换行交互
* 支持持久化保留大纲面板展开状态
* 改进标签列表和账号刷新按钮

### 修复缺陷

* 行级元素设置异常
* 新窗口全屏后面包屑无法点击
* 行级元素嵌套编辑异常

### 开发重构

* 升级 mermaid v10.8.0

### 开发者

* 添加内部内核 API `/api/block/appendDailyNoteBlock`
