## 概述

此版本支持了闪卡设置复习模式。

## 变更记录

以下是此版本中的详细变更。

### 改进功能

* 支持闪卡设置复习模式
* 显示 Mermaid 错误日志并降低渲染抖动
* 支持 F13-32 快捷键配置
* `在上方/下方新建文档` 功能在笔记本级自定义排序时可用
* 改进删除操作后的光标位置
* 改进分隔线下方空格删除操作
* 改进数据库创建列时弹出窗口的性能
* 浮窗中有菜单时保持显示
* 关闭所有编辑器后更新大纲
* 数据库关联字段候选值不再受视图过滤影响
* 改进数据库表格视图选择列交互
* 光标在行级工具栏上时不再触发停靠栏
* 改进移动端 `＋` 菜单
* 支持禁用列表项圆点/数字单击聚焦
* 只读模式下显示嵌入块刷新按钮
* 数据库表格视图模板列支持读取关联、汇总、创建时间和更新时间列
* 改进创建数据库后光标焦点

### 修复缺陷

* 无法设置 Azure OpenAI
* 行级元素 Markdown 编辑异常
* 导出数据库块时日期字段未遵循结束时间开关设置
* 粘贴为纯文本时出现代码
* 退出时关闭用户指南但未关闭编辑器页签

### 开发重构

* 升级 Electron v29.0.1

### 开发者

* 改进内部内核 API `/api/attr/batchSetBlockAttrs`
* 添加内部内核 API `/api/riff/batchSetRiffCardsDueTime`
* 内核 API `/api/riff/getRiffCards` 添加参数 `pageSize`
