## 概述

該版本改進了一些細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 資料庫表格檢視支援同步列寬到其他表格檢視
* 資料庫檢視頁籤支援拖曳排序
* 改進「使用預設列寬」
* 改進主題切換
* 改進拖曳性能
* 改進圖示切換
* 在資料庫卡片檢視的預覽區域中新增「內容塊」選項
* 改進插入塊引用後立即使用快速鍵開啟的體驗
* 改進資料庫卡片視圖卡片右鍵選單
* 改進建立/刪除資料庫視圖後的分頁設定
* 停用資料庫卡片檢視中的自動影片播放
* 圖庫視圖重新命名為卡片視圖
* 設定資料庫視圖排序規則後停用拖曳排序
* 為資料庫數位欄位新增一些貨幣格式支援
* 改進更新資料庫視圖佈局後鏡像資料庫的刷新
* 改進資料庫中的圖片載入效能
* 改進資源搜尋
* 禁用對 /assets/ 路徑的 HTTP 存取
* 改良行動端的麵包屑跳轉
* 在資料庫中新視圖後彈出視圖設定選單
* 當內容為空時，各種圖表不再渲染
* 修復鏡像資料庫顯示視圖
* 改進 Markdown 超連結輸入解析
* 改善搜尋結果高亮
* 改進右鍵選單貼上功能
* 資料庫卡片檢視中綁定的標題塊在預覽區域顯示子塊
* 改進移動容器塊後引用計數的更新
* 改進轉換標題塊層級後引用計數的更新
* 改進文件轉換為標題後引用計數的更新
* 改進資料庫表格視圖固定欄位的複製貼上
* 改進 HTML 表格剪輯
* 改進 HTML 程式碼塊剪輯
* 改進將網路資源轉換為本地資源
* 改進移動標題塊後引用計數的更新
* 設定屬性後不再為塊元素新增 `id` 屬性
* 匯出的 Markdown 行內程式碼不再包含零寬空格

### 修復缺陷

* 行動端鑑權頁面的「記住我」功能無效
* 選擇內容塊後 AI 操作無效
* 包含 `\\u0000` 的 Markdown 表格文件匯入後無法開啟
* 字型 Noto Sans SC 不可用
* 虛擬引用關鍵字排除清單在某些情況下不起作用
* HarmonyOS NEXT 上渲染 PlantUML 不應跳到瀏覽器
* 複製塊時未複製屬性
* 行級備註元素中的 XSS 漏洞

### 開發重構

* 更新 SCSS 依賴並修復警告
* 升級至 Electron v37.2.3

### 開發者

* 在開發環境中啟用樣式表 sourceMaps
* 為 `input-search` 事件匯流排新增 config.query
* 改進內核 API `/api/block/updateBlock` 和 `/api/block/batchUpdateBlock`
* 為插件選項新增 `IProtyleOptions.click.preventInsetEmptyBlock`
* 改進 `showMessage()` 函數
* 新增外掛程式 `saveLayout`
* 新增核心 API `/api/av/batchSetAttributeViewBlockAttrs`
* 新增核心 API `/api/av/batchReplaceAttributeViewBlocks`
* 新增一些核心批次插入塊的 API
