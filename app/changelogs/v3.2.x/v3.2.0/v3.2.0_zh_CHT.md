## 概述

資料庫圖庫視圖現已發布！

## 變更記錄

以下是此版本中的詳細變更。

### 引入特性

* 資料庫圖庫視圖

### 改進功能

* 改進多選塊
* 在行動裝置上公式左右滑動不再打開側邊欄
* 改進塊圖示顯示
* 按住 Shift 時無法拖曳清單項目的點
* 行動裝置上的塊引用彈窗會被鍵盤遮擋
* 登入時新增「記住我」複選框以儲存會話
* 在非空塊中貼上 `/^\s*&gt;|\*|-|\+|\d*.|\[ \]|[x]` 不轉換
* 在 Android 上點選工具列 + 後關閉鍵盤
* 如果不存在筆記本，隱藏「已關閉筆記本」元素
* 改進自訂塊字體大小後列表、程式碼塊和標題的比例
* 改進表格匯出的對齊方式
* 無法從 .protyle-action 元素開始選擇
* 改進帶子文件的空白文件匯出
* 將文件轉換為標題時移除 `title` 屬性
* 改進超連結/圖片標題的轉義
* 匯出合併子文件時忽略最後一個空白段落塊
* 新增葡萄牙巴西語支援
* 在資料庫塊選單中新增「複製資料庫 ID」
* 支援剪藏網頁後開啟文件
* 資料庫支援設定顯示欄位圖示
* 改進 HTML 公式剪藏
* 改進資料庫載入效能
* 改進 HTML 表格剪藏
* 改進貼到微信公眾號
* 動態圖示不再顯示網路圖片角標
* Android 檢查 WebView 版本 95+
* 匯出預覽無法複製圖片
* 造訪認證失敗時刷新頁面跳到認證頁面
* 改進搜尋設定
* 資料庫支援設定欄位換行
* 資料庫相同視圖的不同版面配置使用相同的篩選、排序、分頁和自訂排序規則
* 資料庫索引內容/Markdown 值不再包含零寬空格

### 移除功能

* 完全移除 Google Analytics

### 修復缺陷

* 嵌入塊產生多餘的 HTML
* 匯出 Word/HTML 時內聯程式碼後的文字遺失
* Android 上工具列內容無法滑動
* 自訂 Emoji 檔案導致的 XSS 漏洞

### 開發重構

* 升級 abcjs 6.2.2 至 6.5.0
* 升級至 Electron v37.2.0
* 升級 visjs 9.1.2 至 9.1.13

### 開發者

* 新增內核 API `/api/block/getBlockDOMs`
* 為內核 API `/api/export/exportMdContent` 新增 `fillCSSVar` 參數
