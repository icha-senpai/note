## 概述

此版本改進了一些細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 在文件區塊選單中新增 `複製全文` 選項
* 反向連結面板中的清單在貼上後不再自動折疊
* 改進貼上連結
* 改進當清單項目包含區塊引用或提示區塊時的區塊標渲染
* 改進包含反引號和與號的行級程式碼的貼上
* 改進按鈕陰影效果
* 改進市集清單卡
* 改進區塊引用導出
* `優化排版` 忽略全角字元
* 將閃卡管理視窗中的分頁和導覽按鈕移到左上角
* 支援顯示完整的停靠列面板標題和操作按鈕
* 改進塊標的顯示位置
* 載入圖示不再覆蓋整個雲端設定介面
* 改進分割畫面佈局
* 已下載的市集包不再回退取得線上 README

### 修復缺陷

* macOS 上預設工作空間資料會遺失
* 將區塊拖曳到反向連結面板時會導致報錯
* 修復一些安全漏洞
* Android 上導入 Markdown.zip 出錯
* 在提示區塊內部拖曳區塊後整個區塊會消失

### 開發者

* 任務清單支援 `data-task` 狀態屬性
* 為插件 API `getAllTabs` 新增 `type` 參數
* 新增核心 API `/api/file/workspaceCopyFiles`
* 新增內核 API `/api/block/updateTaskListItemMarker`
* 新增核心 API `/api/block/batchUpdateTaskListItemMarker`
