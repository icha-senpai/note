## 概述

此版本改進了一些細節。

## 變更記錄

以下是此版本中的詳細變更。

### 改進功能

* 改進使用 `快速制卡` 後執行撤銷的邏輯
* 改進資料庫關聯欄位的預設圖示
* 改進關閉使用者指南筆記本的體驗
* 改進區塊連結的匯出
* 改進在啟用或停用外掛程式時停靠列圖示的持久性
* 改進發布服務的安全性
* RTL（從右到左文字方向）不應應用於行級公式
* 改進桌面端主視窗的載入
* 改進退出時的資料同步
* 改進資料庫預覽圖片載入

### 修復缺陷

* 修復若干安全漏洞

### 開發者

* 新增內核 API `/api/setting/setTheme`
* 新增內核 API `/api/ui/reloadTheme`
* 新增一個顯示所有表情符號的 HTML 頁面
