## Scribli 4.0.9

This release improves everyday editing, database boards, settings, and recovery.

### Improvements

* Add and manage Kanban columns directly, with optional To do, In progress, and Done starters.
* Hide the empty uncategorized Kanban column until it contains cards.
* Move cards with a drag grip or a keyboard-accessible Move to column menu.
* Keep Add column accessible when a wide board is scrolled sideways.
* Preserve database view configuration, category values, filters, and template defaults when undoing deletions.
* Queue settings saves to preserve rapid edits, with saving, saved, failure, and retry feedback.
* Correct the selected path in filtered Recent Documents results.
* Search for canvas documents, blocks, databases, and assets, and import local files with automatic labels.
* Add clear empty search results and reset controls to Settings and Command Palette.
* Separate onboarding Settings from optional sync setup, and expose the Off sync provider.
* Hide the unavailable Inbox entry and improve bookmark, tag, and flashcard empty states.
* Add Recently deleted recovery with Restore wording and persistent Recent exports destinations.
* Improve toolbar and dock keyboard controls, accessible labels, and tooltip click behavior.
* Handle closing database settings while a layout change is saving.
