## Scribli 4.0.10

This release adds shared custom colors and database calendar views, with improvements to search and workspace safety.

### Improvements

* Choose custom HEX or RGB colors for text, highlights, database categories, conditional rules, and Canvas cards and connectors.
* Save named palettes and recent colors in the workspace so they survive restarts.
* Customize interface accent, background, panels, and text separately for light and dark modes.
* Add database month calendars with date ranges, undated entries, drag scheduling, and undo.
* Apply ordered conditional colors to Table, Card, Kanban, and Calendar views.
* Rank frequently used slash commands first, with an Editor settings switch.
* View a manually refreshed workspace storage breakdown in App settings.
* Search attachment image alt/title metadata and existing local OCR text.

### Fixes

* Keep temporary document I/O failures separate from genuine document corruption.
* Abort database cleanup when reference scans are incomplete.

### Compatibility

Databases using Calendar views, conditional colors, or custom category colors require Scribli database spec 6. Older installed 4.0.9 builds cannot open these databases. Ordinary databases retain spec 5; no bulk workspace migration is performed.
